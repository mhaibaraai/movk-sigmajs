## 用法

输入即时回显，检索按防抖触发，命中片段自带高亮，选中后相机聚焦过去。默认外观已经接好键盘：上下键移动高亮项（越界回绕）、回车选中（未高亮时取第一条）、Esc 清空。

::warning
默认外观没有把高亮项滚动进可视区，也没有接 `aria-activedescendant`。结果条数多且对无障碍有要求时，用 `#input` 与 `#results` 自行补齐。
::

### `fields`

参与匹配的属性名，按顺序取第一个命中的作展示。下面这份数据集的节点带 `label` 与 `category` 两个可检索字段：

::component-example
---
name: SearchControlFieldsExample
options:
  - name: fields
    label: fields
    items: [label, category]
    multiple: true
    default: [label]
  - name: edges
    label: edges
    items: [true, false]
    default: false
---
::

### `edges`

是否同时检索边。边命中后经 `graph.source(edge)` 定位，相机聚焦到边的**源节点**。匹配只认字符串属性，所以边上得有可匹配的字段——这份数据集的边标签是「源—目标」，勾上之后搜人名会连带出它的关联边。

### `limit`

结果条数上限，超出的直接截断：

::component-example
---
name: SearchControlLimitExample
options:
  - name: limit
    label: limit
    type: number
    default: 10
  - name: debounce
    label: debounce
    type: number
    default: 200
---
::

::note
`limit` 在这里默认 `10`，比 [`useSigmaSearch()`](/docs/composables/use-sigma-search) 自身的 `20` 小——下拉列表放不下那么多。
::

### `debounce`

输入到发起检索的间隔，单位毫秒。输入框的值即时更新用于显示，真正参与匹配的词是防抖之后的——万级节点上每次按键都全量扫一遍会把输入卡住。

结果列表的展开与否看的是**即时值**（非空即展开），不是防抖后的词，所以输入的一瞬间列表就出现，内容稍后填上。上面那条选择条调到 `1000` 就能看清两级的分界。

::note
`fields` / `limit` / `edges` 在 setup 时读一次就交给了 `useSigmaSearch()`，挂载后改这三个 prop 不会重新配置检索。它们通常是静态的，需要动态切换请自己用 composable 接（上面两个示例是靠换 `key` 强制重建才做到即时生效的）。
::

### `placeholder`

输入框占位文本：

::component-example
---
name: SearchControlTextExample
options:
  - name: placeholder
    label: placeholder
    default: 检索节点
  - name: emptyText
    label: emptyText
    default: 无匹配
---
::

### `emptyText`

有检索词但没有结果时的提示文本，输入一个匹配不到的词即可看到。

### 接管输入框与结果项

作用域连行为一起给——只暴露数据的话，接管外观就等于丢掉键盘导航与聚焦。`#input` 的 `onKeydown` 一次绑完全部按键，也可以只用 `move` / `confirm` / `clear` 自定义按键映射；`#option` 的 `segments` 是已经按当前检索词切好的高亮片段；`#empty` 没有作用域：

:component-example{name="SearchControlSlotExample"}

#### `#input`

::field-group
  :::field{name="modelValue" type="string"}
  输入框即时值，不是防抖后参与匹配的词。
  :::

  :::field{name="placeholder" type="string"}
  透传自 `placeholder` prop。
  :::

  :::field{name="open" type="boolean"}
  结果列表是否展开，绑给 `aria-expanded`。
  :::

  :::field{name="activeIndex" type="number"}
  当前键盘高亮项下标，未选中为 `-1`。
  :::

  :::field{name="onUpdate()" type="(value: string) => void"}
  写回输入值。
  :::

  :::field{name="onKeydown()" type="(event: KeyboardEvent) => void"}
  上下键、回车、Esc 的完整处理。
  :::

  :::field{name="move()" type="(delta: number) => void"}
  按增量移动高亮项，越界回绕。
  :::

  :::field{name="confirm()" type="() => void"}
  选中当前高亮项，未高亮时取第一条。
  :::

  :::field{name="clear()" type="() => void"}
  清空输入与高亮。
  :::
::

#### `#option`

::field-group
  :::field{name="result" type="SigmaSearchResult"}
  该条结果。
  :::

  :::field{name="segments" type="HighlightSegment[]"}
  已切好的命中片段。`HighlightSegment` 是 `{ text: string, match: boolean }`，来自 `@movk/core`。
  :::
::

### 接管整个下拉

`#results` 接管的是**整个下拉容器**：

:component-example{name="SearchControlResultsExample"}

::warning
一旦接管，`#option` 与 `#empty` 不再渲染，`.sigma-search-results` 的绝对定位、滚动上限与「停靠在底部时向上展开」的规则也一并失效，都得自己处理。开发环境下同时提供 `#results` 与 `#option` / `#empty` 会有一条控制台告警。
::

::field-group
  :::field{name="results" type="SigmaSearchResult[]"}
  当前检索结果。
  :::

  :::field{name="activeIndex" type="number"}
  当前键盘高亮项下标，未选中为 `-1`。
  :::

  :::field{name="query" type="string"}
  防抖后真正参与匹配的词。
  :::

  :::field{name="highlight()" type="(result: SigmaSearchResult) => HighlightSegment[]"}
  按当前 `query` 切出命中片段。
  :::

  :::field{name="choose()" type="(result: SigmaSearchResult) => Promise<void>"}
  聚焦到该结果、抛出 `select` 事件并清空输入。
  :::
::

类型从根出口取：

```ts
import type { SigmaSearchResult } from '@movk/sigma'
```
