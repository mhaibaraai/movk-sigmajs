## 用法

输入即时回显，检索按防抖触发，命中片段自带高亮，选中后相机聚焦过去：

:component-example{name="SearchControlExample"}

`select` 事件在相机动画**结束后**才抛出，携带完整的结果对象。

### 两级输入

输入框的值即时更新用于显示，真正参与匹配的词是防抖之后的——万级节点上每次按键都全量扫一遍会把输入卡住。`debounce` 默认 `200` 毫秒。

结果列表的展开与否看的是**即时值**（非空即展开），不是防抖后的词，所以输入的一瞬间列表就出现，内容稍后填上。

::note
`fields` / `limit` / `edges` 在 setup 时读一次就交给了 [`useSigmaSearch()`](/docs/composables/use-sigma-search)，挂载后改这三个 prop 不会重新配置检索。它们通常是静态的，需要动态切换请自己用 composable 接。

另外 `limit` 在这里默认 `10`，比 `useSigmaSearch()` 自身的 `20` 小——下拉列表放不下那么多。
::

### 键盘

默认外观已经接好：上下键移动高亮项（越界回绕）、回车选中（未高亮时取第一条）、Esc 清空。

::warning
默认外观没有把高亮项滚动进可视区，也没有接 `aria-activedescendant`。结果条数多且对无障碍有要求时，用 `#input` 与 `#results` 自行补齐。
::

### 四个插槽，逐层接管

作用域连行为一起给——只暴露数据的话，接管外观就等于丢掉键盘导航与聚焦。

`#input` 换输入框，`onKeydown` 一次绑完全部按键；也可以只用 `move` / `confirm` / `clear` 自定义按键映射：

```vue
<template>
  <SigmaSearchControl>
    <template #input="{ modelValue, placeholder, open, onUpdate, onKeydown }">
      <UInput
        :model-value="modelValue"
        :placeholder="placeholder"
        :aria-expanded="open"
        role="combobox"
        @update:model-value="onUpdate"
        @keydown="onKeydown"
      />
    </template>
  </SigmaSearchControl>
</template>
```

`#option` 换单条结果的内容，`segments` 是已经按当前检索词切好的高亮片段：

```vue
<template>
  <SigmaSearchControl>
    <template #option="{ result, segments }">
      <span v-for="(segment, index) in segments" :key="index" :class="{ hit: segment.match }">
        {{ segment.text }}
      </span>
      <UBadge>{{ result.field }}</UBadge>
    </template>
  </SigmaSearchControl>
</template>
```

`#empty` 换无结果时的提示（无作用域）。

::warning
`#results` 接管的是**整个下拉容器**。一旦接管，`#option` 与 `#empty` 不再渲染，`.sigma-search-results` 的绝对定位、滚动上限与「停靠在底部时向上展开」的规则也一并失效，都得自己处理。开发环境下同时提供 `#results` 与 `#option` / `#empty` 会有一条控制台告警。
::

## API

### Props

:component-props{slug="SigmaSearchControl"}

### Emits

:component-emits{slug="SigmaSearchControl"}

::field-group
  :::field{name="select" type="[result: SigmaSearchResult]"}
  选中某条结果时触发。在相机动画结束后抛出。
  :::
::

### Slots

:component-slots{slug="SigmaSearchControl"}

#### input

::field-group
  :::field{name="modelValue" type="string"}
  输入框即时值，不是防抖后参与匹配的词。
  :::

  :::field{name="placeholder" type="string"}
  透传自 `placeholder` prop。
  :::

  :::field{name="open" type="boolean"}
  结果列表是否展开，绑给 `aria-expanded`。
  :::

  :::field{name="activeIndex" type="number"}
  当前键盘高亮项下标，未选中为 `-1`。
  :::

  :::field{name="onUpdate()" type="(value: string) => void"}
  写回输入值。
  :::

  :::field{name="onKeydown()" type="(event: KeyboardEvent) => void"}
  上下键、回车、Esc 的完整处理。
  :::

  :::field{name="move()" type="(delta: number) => void"}
  按增量移动高亮项，越界回绕。
  :::

  :::field{name="confirm()" type="() => void"}
  选中当前高亮项，未高亮时取第一条。
  :::

  :::field{name="clear()" type="() => void"}
  清空输入与高亮。
  :::
::

#### results

::field-group
  :::field{name="results" type="SigmaSearchResult[]"}
  当前检索结果。
  :::

  :::field{name="activeIndex" type="number"}
  当前键盘高亮项下标，未选中为 `-1`。
  :::

  :::field{name="query" type="string"}
  防抖后真正参与匹配的词。
  :::

  :::field{name="highlight()" type="(result: SigmaSearchResult) => HighlightSegment[]"}
  按当前 `query` 切出命中片段。`HighlightSegment` 是 `{ text: string, match: boolean }`，来自 `@movk/core`。
  :::

  :::field{name="choose()" type="(result: SigmaSearchResult) => Promise<void>"}
  聚焦到该结果、抛出 `select` 事件并清空输入。
  :::
::

#### option

::field-group
  :::field{name="result" type="SigmaSearchResult"}
  该条结果。
  :::

  :::field{name="segments" type="HighlightSegment[]"}
  已切好的命中片段。
  :::
::

#### empty

无作用域，替换无结果时的提示内容。

类型从根出口取：

```ts
import type { SigmaSearchResult } from '@movk/sigma'
```
