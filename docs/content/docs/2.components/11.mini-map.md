## 用法

放进 `SigmaControls` 即可。放大后视口框出现，点缩略图任意位置把相机移过去：

:component-example{name="MiniMapExample" client-only="true" class="example-stage"}

组件自己画一张 `canvas`，不再创建 sigma 实例——所以它**不占用额外的 WebGL 上下文**，可以放心和多张图一起用。

### 全程 framed 坐标

`getNodeDisplayData()` 返回的是 framed 坐标，相机的 `x` / `y` 也在这个坐标系。于是画节点、画视口框、点击回写三件事同处一个坐标系，不必来回换算，也就没有混用坐标导致错位的机会。

视口框由 `viewportToFramedGraph()` 取画布两个对角点得到，节点被 reducer 标为 `hidden` 时不参与包围盒计算，也不绘制。全图没有可见节点时缩略图整个清空。

### 改颜色只能靠 CSS 变量

绘制时经 `getComputedStyle` 读两个变量，没有对应的 prop：

::field-group
  :::field{name="--sigma-minimap-node" type="color"}
  节点的填充色，默认 `var(--sigma-color-muted)`。
  :::

  :::field{name="--sigma-minimap-viewport" type="color"}
  视口框的描边色，默认 `var(--sigma-color-accent)`。
  :::

  :::field{name="--sigma-minimap-size" type="length"}
  缩略图的边长，默认 `140px`。缩略图是正方形。
  :::
::

```css
.sigma-root {
  --sigma-minimap-size: 180px;
  --sigma-minimap-viewport: #f43f5e;
}
```

重绘经 `requestAnimationFrame` 合并，由画布重绘、容器缩放两个信号驱动。画布按 `devicePixelRatio` 放大后备存储，高分屏上不糊。

### 点击只平移

`clickToMove` 触发的是相机的 `animate({ x, y })`——只改位置，**不改 `ratio`**。缩略图上点一下不会顺带改变缩放级别，这样它和 `SigmaZoomControl` 各管各的。

::note
组件没有插槽。需要完全不同的缩略图（比如带节点标签、带热力叠加）时，自己用 `useSigma()` 拿实例画一张，这个组件不打算做成通用画布。
::
