## 用法

放进 `SigmaGraph` 即可工作，无需接线：

:component-example{name="TooltipExample" client-only="true" class="example-stage"}

不给插槽时展示节点或边的 `label`，缺失则退回图元的 key。

### 插槽作用域

插槽以 `{ id, type, attributes }` 暴露命中项：

```vue
<template>
  <SigmaTooltip>
    <template #default="{ id, type, attributes }">
      <strong>{{ attributes.label ?? id }}</strong>
      <span>{{ type === 'node' ? attributes.category : '关系' }}</span>
    </template>
  </SigmaTooltip>
</template>
```

::note
键名是 `id` 而不是 `key`——`key` 是 Vue 的保留属性，作用域里放不进去。`SigmaContextMenu` 同理。
::

`attributes` 是该节点或边的完整属性对象，图元已从图上移除时为 `{}`。

### 关闭只能靠模板 ref

与 `SigmaPopover` / `SigmaContextMenu` 不同，本组件的插槽作用域里**没有** `close`——提示层跟着指针走，没有「用户主动关掉」这回事。确实需要程序化关闭时经模板 ref：

```vue
<script setup lang="ts">
const tooltip = useTemplateRef('tooltip')

function onSomething() {
  tooltip.value?.hide()
}
</script>

<template>
  <SigmaTooltip ref="tooltip" />
</template>
```

点击画布空白处始终会关闭。

### 边的锚点是源节点

边没有单一锚点，组件退化到用 `graph.source(edge)` 定位——提示层会贴在边的源节点上，而不是鼠标位置或边的中点。

::warning
`target` 含 `'edge'` 或 `'both'` 时，必须先在 `settings` 里开 `enableEdgeEvents: true`。这是 sigma 的默认行为——边的命中检测有额外开销，默认关闭——不是本库的限制。
::

## API

### Props

:component-props{slug="SigmaTooltip"}

### Slots

:component-slots{slug="SigmaTooltip"}

默认插槽作用域：

::field-group
  :::field{name="id" type="string"}
  命中的节点或边的 key。用 `id` 而非 `key`，后者是 Vue 的保留属性。
  :::

  :::field{name="type" type="'node' | 'edge'"}
  命中的图元类型。
  :::

  :::field{name="attributes" type="Attributes"}
  该图元的完整属性对象，类型来自 `graphology-types`。图元已被移除时为 `{}`。
  :::
::

### Expose

经 [`useTemplateRef`](https://vuejs.org/api/composition-api-helpers.html#usetemplateref) 访问该组件实例。

::field-group
  :::field{name="hide()" type="() => void"}
  关闭当前提示层。
  :::
::
