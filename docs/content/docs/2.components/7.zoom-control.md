### 换图标

三个按钮各有具名插槽——`zoom-in`、`zoom-out`、`reset`。它们**只负责图标**，没有作用域：点击行为、`type="button"`、`aria-label`、`title` 都由库提供，接管外观不会丢掉无障碍结构。

```vue
<template>
  <SigmaZoomControl :labels="['放大', '缩小', '回到全图']">
    <template #zoom-in>
      <UIcon name="i-lucide-plus" />
    </template>
    <template #zoom-out>
      <UIcon name="i-lucide-minus" />
    </template>
    <template #reset>
      <UIcon name="i-lucide-locate-fixed" />
    </template>
  </SigmaZoomControl>
</template>
```

默认图标是 `+`、`−`（U+2212 减号，不是连字符）、`⌖`。`labels` 三项依次对应放大、缩小、复位，同时用作 `aria-label` 与 `title`。

::note
`reset="false"` 时复位按钮整个不渲染，`labels` 的第三项随之无效。
::

### factor 不作用于复位

放大与缩小按 `factor` 倍缩放，复位按钮只吃 `duration`——它调的是相机的 `animatedReset()`，回到初始视角这件事没有倍数可言。

需要「容纳全图」而不是「回到初始视角」，用 `useSigmaCamera().fitTo()` 自己接一个按钮，那需要可选 peer `@sigma/utils`。

## API

### Props

### Slots

:component-slots{slug="SigmaZoomControl"}

三个插槽都没有作用域，只替换按钮内的图标内容：

::field-group
  :::field{name="zoom-in"}
  放大按钮的图标，默认 `+`。
  :::

  :::field{name="zoom-out"}
  缩小按钮的图标，默认 `−`。
  :::

  :::field{name="reset"}
  复位按钮的图标，默认 `⌖`。仅在 `reset` 为 `true` 时渲染。
  :::
::
