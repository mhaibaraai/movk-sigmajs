## 用法

按某个节点属性聚合，每组显示代表色与节点数，点击切换显隐：

:component-example{name="LegendExample" client-only="true" class="example-stage"}

::warning
`field` 默认取 `'type'`，但在 sigma 里 `type` 是**渲染程序名**，不是业务分类。领域分类几乎总要显式传自己的字段，比如 `field="category"`。
::

组色取该组**首个遇到的**节点的 `colorField` 属性，缺失时回落到字面量 `'currentColor'`（即跟随文字颜色）。同组节点颜色不一致时以第一个为准，图例不会去做平均或投票。

### 显隐只在视图层

切换走的是 [`useSigmaFilter()`](/docs/composables/use-sigma-filter)，落到一组视觉不可见但正常参与渲染的显示字段上（不是 `visibility: 'hidden'`，原因见该文档）——**图数据一个字节都没动**。被隐藏的节点仍然参与邻域计算与检索，取消隐藏时立刻回来，不需要重新加载数据。

连带效果：`useSigmaFilter` 默认 `hideDanglingEdges: true`，端点被隐藏的边也会一并隐藏。

`order` 默认 `200`，高于选中高亮的 `100`，但这个次序不再是必须的——`useSigmaSelection()` 的淡出归约会主动跳过已过滤的节点/边，不依赖谁在链上排得更靠后。

::note
`order` 只在 setup 时读一次，挂载后改这个 prop 不会重新登记。
::

### 插槽连行为一起给

作用域除了 `groups`，还给了 `toggle` 与 `reset`。只给数据的话，接管外观就等于丢掉显隐切换——这与「封装是加法」的前提相悖：

```vue
<template>
  <SigmaLegend field="category">
    <template #default="{ groups, toggle, reset }">
      <UButton
        v-for="group in groups"
        :key="group.value"
        :variant="group.visible ? 'solid' : 'ghost'"
        @click="toggle(group.value)"
      >
        <span :style="{ background: group.color }" class="swatch" />
        {{ group.value }} ({{ group.count }})
      </UButton>
      <UButton variant="link" @click="reset">
        全部显示
      </UButton>
    </template>
  </SigmaLegend>
</template>
```

`toggleable="false"` 时 `toggle()` 是空操作，默认外观下的按钮也会置为 `disabled`。

## API

### Props

:component-props{slug="SigmaLegend"}

### Slots

:component-slots{slug="SigmaLegend"}

默认插槽作用域：

::field-group
  :::field{name="groups" type="SigmaLegendGroup[]"}
  聚合结果，随图变化自动重算。

    ::::collapsible
      :::::field-group
        ::::::field{name="value" type="string"}
        分组值，取自节点的 `field` 属性；缺失时为 `fallback`。
        ::::::

        ::::::field{name="color" type="string"}
        该组的代表色，取该组首个节点的 `colorField` 属性，缺失时为 `'currentColor'`。
        ::::::

        ::::::field{name="count" type="number"}
        该组的节点数。
        ::::::

        ::::::field{name="visible" type="boolean"}
        当前是否可见。
        ::::::
      :::::
    ::::
  :::

  :::field{name="toggle()" type="(value: string) => void"}
  切换某组的显隐。`toggleable` 为 `false` 时是空操作。
  :::

  :::field{name="reset()" type="() => void"}
  全部恢复显示，并清空节点过滤器。
  :::
::

### Expose

经 [`useTemplateRef`](https://vuejs.org/api/composition-api-helpers.html#usetemplateref) 访问该组件实例。

::field-group
  :::field{name="reset()" type="() => void"}
  全部恢复显示，与插槽作用域里的同名方法一致。
  :::
::

::note
`SigmaLegendGroup` 声明在组件的 `<script setup>` 里，目前**不在** Movk Sigma 的根出口中。接管插槽时作用域类型由 Vue 自行推断，通常不必显式标注。
::
