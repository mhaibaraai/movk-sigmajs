## 用法

sigma 把图画在 canvas 上，canvas 里没有 DOM 也就没法放按钮、表单、富文本。`SigmaOverlay` 是一块普通的 `div`，位置由库负责跟着画布同步——里面放什么由你决定。

`SigmaTooltip`、`SigmaPopover`、`SigmaContextMenu` 都建在它之上。需要完全自定义的浮动内容时才直接用它。

### 两套坐标系

这是最容易踩的坑：锚到 `node` 与锚到 `position` 走的是**不同**的换算函数。

`getNodeDisplayData()` 返回的是 sigma 归一化后的 framed 坐标，必须走 `framedGraphToViewport()`；而 `position` 吃的是原始图坐标，走 `graphToViewport()`。组件内部已经分好，但自己写覆盖层时混用会让内容整体错位。

### 锚点在左上角

组件把位置写成内联 `transform: translate(...)`，元素的**左上角**落在锚点上。要居中或者放在锚点上方，在你自己的内容上加 `translate`：

```vue
<template>
  <SigmaOverlay node="a" :offset="[0, -24]">
    <div class="badge">
      标签
    </div>
  </SigmaOverlay>
</template>

<style scoped>
.badge {
  /* 水平居中、底边贴住锚点 */
  translate: -50% -100%;
}
</style>
```

内置的 `.sigma-tooltip` 与 `.sigma-popover` 就是这么做的。`offset` 则用于纯像素级的微调，比如把气泡从节点圆心推到圆周之外。

### 隐藏时插槽内容要自己跳过

组件用 `v-show` 保留 DOM，只切 `display`。这样重新出现时不必重建，但也意味着**插槽内容始终存在**——隐藏期间它照样渲染，也照样能被点到。

::warning
插槽内容必须自行 `v-if`，否则使用方拿到的作用域是空的，隐藏的内容还能响应点击。上面三个派生组件都在插槽上加了 `v-if`，直接用 `SigmaOverlay` 时要自己补。
::

节点被 reducer 标为 `hidden`、或从图上移除时，覆盖层自动隐藏。

::note
`.sigma-overlay` 的 `pointer-events` 是 `none`，鼠标事件会穿透到画布上。里面要放可点击的东西，在你自己的元素上恢复 `pointer-events: auto`——`.sigma-popover` 与 `.sigma-context-menu` 已经这么做了。
::
