## 用法

写一个谓词，返回 `true` 保留、`false` 隐藏：

:component-example{name="UseSigmaFilterExample" client-only="true" class="example-stage"}

```vue [UseSigmaFilterPanel.vue]
<script setup lang="ts">
const { nodeFilter, only, reset, hiddenCount } = useSigmaFilter()

// 按属性过滤
nodeFilter.value = (key, attributes) => attributes.category === '技术标准'

// 或者直接给一批 key
only(neighborhood('n0'))
</script>
```

### 只动视图层

过滤落到 sigma 的 `hidden` 显示标志上，**图数据一个字节都没动**。这带来几个直接后果：

- 被隐藏的节点仍在 graphology 里，邻域计算与检索照常能看到它们
- 取消过滤是瞬时的，不需要重新加载数据
- `graph.export()` 导出的仍是全量数据，过滤状态不会被带走

需要真正删掉数据，那是 `graph.dropNode()` 的事，不是这里。

### 换谓词才触发重绘

库监听的是 `nodeFilter` / `edgeFilter` 两个 ref 的**赋值**。在既有闭包里改状态不会触发重绘：

```ts
const keyword = shallowRef('')
const { nodeFilter } = useSigmaFilter()

// 错：谓词只赋值一次，之后改 keyword 不会重绘
nodeFilter.value = (_key, attrs) => String(attrs.label).includes(keyword.value)

// 对：每次都重新赋值
watch(keyword, (value) => {
  nodeFilter.value = (_key, attrs) => String(attrs.label).includes(value)
})
```

`only(null)` 只清 `nodeFilter`，`edgeFilter` 保持不变；`reset()` 才是两个都清。

### 边的隐藏有两条路径

先看显式的 `edgeFilter`，再看悬空边规则。`hideDanglingEdges` 默认开启：任一端点被隐藏时该边一并隐藏——否则会看到一堆连向空白处的断线。

这条规则只在 `nodeFilter` 非空时生效。

::note
`order` 默认 `50`，排在选中高亮的 `100` 之前——先隐藏，再谈高亮。图例的 `200` 又在两者之后，因为它要压得过高亮的配色才能真正把节点藏掉。

`order` 在 setup 时读取一次。
::

### hiddenCount 是 O(n)

每次图变更或谓词更换都会全量遍历一遍节点。`nodeFilter` 为 `null` 时直接返回 `0`，不遍历。万级图上频繁触发要留意；只是用来显示「已隐藏 N 项」的话没有问题。

## API

### useSigmaFilter()

`useSigmaFilter(options?: UseSigmaFilterOptions): UseSigmaFilterReturn`{lang="ts-type"}

#### Options

::field-group
  :::field{name="order" type="number"}
  默认 `50` —— reducer 链内次序。默认排在选中高亮之前，先隐藏再谈高亮。仅在 setup 时读取一次。
  :::

  :::field{name="hideDanglingEdges" type="boolean"}
  默认 `true` —— 任一端点被隐藏时一并隐藏该边。仅在 `nodeFilter` 非空时生效。
  :::
::

#### Returns

::field-group
  :::field{name="nodeFilter" type="Ref<SigmaNodePredicate | null>"}
  节点谓词，可写。为 `null` 表示不过滤。重新赋值才触发重绘。
  :::

  :::field{name="edgeFilter" type="Ref<SigmaEdgePredicate | null>"}
  边谓词，可写。为 `null` 表示不过滤。
  :::

  :::field{name="only()" type="(keys: Iterable<string> | null) => void"}
  只保留给定的节点。传 `null` 清空节点谓词，不影响边谓词。
  :::

  :::field{name="reset()" type="() => void"}
  清空所有过滤。
  :::

  :::field{name="hiddenCount" type="ComputedRef<number>"}
  当前被隐藏的节点数。无节点谓词时为 `0`。
  :::
::

`SigmaNodePredicate` 与 `SigmaEdgePredicate` 的形态都是 `(key: string, attributes: Attributes) => boolean`，返回 `true` 表示保留。类型从根出口取：

```ts
import type { SigmaEdgePredicate, SigmaNodePredicate, UseSigmaFilterOptions, UseSigmaFilterReturn } from '@movk/sigma'
```
