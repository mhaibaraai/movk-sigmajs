## 用法

调用一次即可，无需接线：

:component-example{name="UseSigmaDragExample" client-only="true" class="example-stage"}

```vue [UseSigmaDragPanel.vue]
<script setup lang="ts">
const { dragged, isDragging, stop } = useSigmaDrag({
  onEnd: (node) => {
    // 拖完把坐标存回服务端
    $fetch(`/api/graph/nodes/${node}/position`, {
      method: 'PATCH',
      body: { x: graph.value.getNodeAttribute(node, 'x'), y: graph.value.getNodeAttribute(node, 'y') }
    })
  }
})
</script>
```

按下节点时会阻止 sigma 的默认行为——不阻止的话，按下节点会被 sigma 当成开始平移相机。

### 与迭代型布局互斥

::warning
ForceAtlas2、Noverlap 这类布局在跑的时候会**持续回写坐标**，拖拽结果会被立刻覆盖，表现为节点怎么拖都弹回去。需要手动摆位时先停掉布局：

```ts
const layout = useSigmaLayout('forceatlas2')
const { isDragging } = useSigmaDrag({
  onStart: () => layout.stop()
})
```
::

一次性布局（`circular`、`circlepack`、`random`，以及 `assign()` 调用）没有这个问题——它们跑完就结束了。

### 画布外释放的兜底

指针移出画布再松开时，sigma 收不到 `up` 事件，节点会一直粘在指针上。库在 `window` 上挂了一个 `mouseup` 兜底，`onEnd` 无论从哪条路径结束都会触发一次。

这个监听有 SSR 保护，服务端不会去碰 `window`。

### enabled 只在按下时读取

`enabled` 在 `downNode` 处理函数内部读取，不是响应式的开关——但因为每次按下都会重读，改动**下一次**按下时就生效。已经在拖的那次不受影响。

```ts
const editable = shallowRef(false)
useSigmaDrag({ enabled: editable.value }) // 错：只捕获了首次的值
```

要动态开关，传一个始终为 `true` 的 `enabled`，然后在 `onStart` 里判断并调 `stop()`；或者更简单，用 `v-if` 控制承载这个 composable 的子组件是否存在。

::note
`highlight` 默认开启，拖拽过程中给节点写 `highlighted` 属性让它在视觉上浮起，松手时移除。节点在拖拽过程中被从图上删掉时会自动收尾。
::

## API

### useSigmaDrag()

`useSigmaDrag(options?: UseSigmaDragOptions): UseSigmaDragReturn`{lang="ts-type"}

#### Options

::field-group
  :::field{name="enabled" type="boolean"}
  默认 `true` —— 是否启用拖拽。每次按下节点时读取一次。
  :::

  :::field{name="highlight" type="boolean"}
  默认 `true` —— 拖拽过程中给节点写 `highlighted`，让它在视觉上浮起。
  :::

  :::field{name="onStart" type="(node: string) => void"}
  拖拽开始时触发。
  :::

  :::field{name="onEnd" type="(node: string) => void"}
  拖拽结束时触发，无论是正常释放还是在画布外释放。
  :::
::

#### Returns

::field-group
  :::field{name="dragged" type="Readonly<Ref<string | null>>"}
  正在拖拽的节点，未拖拽时为 `null`。
  :::

  :::field{name="isDragging" type="ComputedRef<boolean>"}
  是否正在拖拽。
  :::

  :::field{name="stop()" type="() => void"}
  主动结束拖拽。未在拖拽时是空操作。
  :::
::

类型从根出口取：

```ts
import type { UseSigmaDragOptions, UseSigmaDragReturn } from '@movk/sigma'
```
