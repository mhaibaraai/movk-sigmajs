## 用法

调用一次即可，无需接线：

:component-example{name="UseSigmaDragExample" client-only="true" class="example-stage"}

```vue [UseSigmaDragPanel.vue]
<script setup lang="ts">
const { graph } = useSigma()

const { dragged, isDragging } = useSigmaDrag({
  onEnd: (node) => {
    // 拖完把坐标存回服务端
    $fetch(`/api/graph/nodes/${node}/position`, {
      method: 'PATCH',
      body: { x: graph.value.getNodeAttribute(node, 'x'), y: graph.value.getNodeAttribute(node, 'y') }
    })
  }
})
</script>
```

拖拽本身由 sigma v4 内建的 `enableNodeDrag` 实现，本 composable 不重复造：它只负责把开关接上 Vue 的响应式，并把 sigma 的 `nodeDragStart` / `nodeDragEnd` 事件镜像成 ref。

### 拖拽中的外观

被拖拽的节点自带 `isDragged` 状态，改外观走 styles，不必往图数据里写临时属性：

```vue
<SigmaGraph
  :data="data"
  :styles="{
    nodes: [
      { color: { attribute: 'color' }, size: { attribute: 'size' } },
      { whenState: 'isDragged', then: { color: '#f59e0b', labelVisibility: 'visible' } }
    ]
  }"
/>
```

### 一次拖多个节点

传 `settings.getDraggedNodes`，返回哪些节点要跟着一起动。`onStart` / `onEnd` 的第二个参数与 `draggedNodes` 拿到的就是它的返回值：

```vue
<script setup lang="ts">
const graph = new Graph()

// 拖一个节点，它的一度邻居跟着走
const settings = {
  getDraggedNodes: (node: string) => [node, ...graph.neighbors(node)]
}
</script>

<template>
  <SigmaGraph :graph="graph" :settings="settings" />
</template>
```

写回的属性名默认是 `x` / `y`，要写到别的字段上用 `settings.dragPositionToAttributes`——签名是 `(position: Coordinates, node: string) => Record<string, unknown>`{lang="ts-type"}。

### 与迭代型布局互斥

::warning
ForceAtlas2、Noverlap 这类布局在跑的时候会**持续回写坐标**，拖拽结果会被立刻覆盖，表现为节点怎么拖都弹回去。需要手动摆位时先停掉布局：

```ts
const layout = useSigmaLayout('forceatlas2')
const { isDragging } = useSigmaDrag({
  onStart: () => layout.stop()
})
```
::

一次性布局（`circular`、`circlepack`、`random`，以及 `assign()` 调用）没有这个问题——它们跑完就结束了。

::note
布局跑完坐标跨度会大幅变化，v4 默认的 `size` 又是图坐标单位，节点会因此成倍胀大。上面的示例传了 `itemSizesReference: 'screen'` 规避，来龙去脉见[节点尺寸与坐标量级](/docs/guides/node-size)。
::

### enabled 是响应式的

`enabled` 接受 ref、getter 或裸值，变了立刻生效，不必等下一次按下：

```ts
const editable = shallowRef(false)
useSigmaDrag({ enabled: editable })
```

## API

### useSigmaDrag()

`useSigmaDrag(options?: UseSigmaDragOptions): UseSigmaDragReturn`{lang="ts-type"}

#### Options

::field-group
  :::field{name="enabled" type="MaybeRefOrGetter<boolean>"}
  默认 `true` —— 是否启用拖拽。响应式，实际落到 sigma 的 `enableNodeDrag` 设置上。
  :::

  :::field{name="onStart" type="(node: string, allDraggedNodes: string[]) => void"}
  拖拽开始时触发。第二个参数是本次实际会移动的全部节点，由 `settings.getDraggedNodes` 决定。
  :::

  :::field{name="onEnd" type="(node: string, allDraggedNodes: string[]) => void"}
  拖拽结束时触发。
  :::
::

#### Returns

::field-group
  :::field{name="dragged" type="Readonly<Ref<string | null>>"}
  正在拖拽的节点，未拖拽时为 `null`。
  :::

  :::field{name="draggedNodes" type="Readonly<Ref<string[]>>"}
  本次拖拽实际移动的全部节点，未拖拽时为空数组。
  :::

  :::field{name="isDragging" type="ComputedRef<boolean>"}
  是否正在拖拽。
  :::
::

类型从根出口取：

```ts
import type { UseSigmaDragOptions, UseSigmaDragReturn } from '@movk/sigma'
```
