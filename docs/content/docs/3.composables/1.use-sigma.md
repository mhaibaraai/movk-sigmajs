## 用法

这是所有其他 composable 的地基。它返回的 `sigma` 与 `graph` 是**原生实例本身**——不是 Proxy，不是包装对象，任何 sigma / graphology 的方法都可以直接调：

:component-example{name="UseSigmaExample" client-only="true" class="example-stage"}

```vue [UseSigmaPanel.vue]
<script setup lang="ts">
const { sigma, graph, isReady, whenReady } = useSigma()

async function callNative() {
  const instance = await whenReady()

  instance.getCamera().animatedReset({ duration: 400 }) // 原生相机 API
  graph.value.setNodeAttribute('a', 'color', '#a855f7') // 原生 graphology mutation
}
</script>
```

库没覆盖的原生能力，从这里全都拿得到——封装是加法，不是围墙。

### 必须在子树内调用

`useSigma()` 是 `inject`。在 `SigmaGraph` 子树之外调用会直接抛错，错误信息里会提示改用 `useSigmaById()`。

这也是为什么示例总是「渲染图的外壳 + 消费上下文的面板」两个文件——这正是真实应用的结构：

```vue [pages/graph.vue]
<template>
  <SigmaGraph :data="data" style="height: 70vh">
    <GraphPanel />
  </SigmaGraph>
</template>
```

### 等待实例就绪

服务端与挂载完成前 `sigma.value` 恒为 `null`（实例在 `onMounted` 里才创建）。两种应对：

```ts
// 事件回调等「一定在就绪后」的场景，直接 await
const instance = await whenReady()

// 模板里做条件渲染，用 isReady
```

`whenReady()` 在已就绪时立即兑现，不必担心多调一次的开销。`graph` 则始终存在——图数据结构不依赖 WebGL，服务端也有。

::note
库内所有 composable 的异步方法都走了 `whenReady()`，所以在实例创建之前调用它们不会丢失，会排队等到就绪。
::

## API

### useSigma()

`useSigma(): SigmaContext`{lang="ts-type"}

在 `SigmaGraph` 子树之外调用时抛错。

#### Returns

::field-group
  :::field{name="sigma" type="ShallowRef<Sigma | null>"}
  原生 sigma 实例。SSR 期与挂载完成前为 `null`。
  :::

  :::field{name="graph" type="ShallowRef<Graph>"}
  原生 graphology 实例，始终存在。
  :::

  :::field{name="isReady" type="Readonly<Ref<boolean>>"}
  实例是否已创建。
  :::

  :::field{name="whenReady()" type="() => Promise<Sigma>"}
  等待实例就绪，已就绪时立即兑现。
  :::

  :::field{name="registerReducer()" type="(entry: SigmaReducerEntry) => () => void"}
  往 reducer 链登记一条，返回注销函数。通常经 [`useSigmaReducer()`](/docs/composables/use-sigma-reducer) 间接使用。
  :::

  :::field{name="refreshReducers()" type="() => void"}
  重新合成 reducer 链并让 sigma 重绘。
  :::
::

`Sigma` 来自 `sigma`，`Graph` 来自 `graphology`，本库不 re-export 上游，需要时从原包直接 import。本库自己的类型从根出口取：

```ts
import type { SigmaContext } from '@movk/sigma'
```
