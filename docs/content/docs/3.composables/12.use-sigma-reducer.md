## 用法

sigma 的 `nodeReducer` / `edgeReducer` 各只接受一个函数，后设置的会覆盖先设置的——高亮、淡出、过滤、图例显隐这些独立关注点无法直接共存。链把它们按 `order` 升序合成为单个函数：

:component-example{name="UseSigmaReducerExample" client-only="true" class="example-stage"}

```vue [UseSigmaReducerPanel.vue]
<script setup lang="ts">
useSigmaReducer({
  order: 150,
  node: (key, data) => ({
    color: important.value.has(key) ? '#f43f5e' : data.color
  })
})
</script>
```

归约返回的是**补丁**，不是完整的显示数据——只写要改的字段，其余原样带过。

### 链的次序

::field-group
  :::field{name="nodeReducer / edgeReducer"}
  用户经 `SigmaGraph` 的 `nodeReducer` / `edgeReducer` props 自带的归约，**永远是链首基座**，不会被库吞掉。
  :::

  :::field{name="order: 50"}
  [`useSigmaFilter()`](/docs/composables/use-sigma-filter) —— 先隐藏，再谈高亮。
  :::

  :::field{name="order: 100"}
  [`useSigmaSelection()`](/docs/composables/use-sigma-selection) —— 高亮与淡出。
  :::

  :::field{name="order: 200"}
  [`SigmaLegend`](/docs/components/legend) —— 要压得过高亮的配色才能真正把节点藏掉。
  :::
::

`order` 默认 `0`，也就是排在全部内置条目之前。想覆盖内置行为就取一个更大的值。

### 归约函数不变，状态在变

这是最容易困惑的地方：归约函数本身通常是常量，变的是它闭包里读的响应式状态。sigma 不知道闭包变了，需要主动让它重跑：

```ts
const threshold = shallowRef(5)

const { refresh } = useSigmaReducer({
  node: (key, data) => ({
    hidden: graph.value.degree(key) < threshold.value
  })
})

watch(threshold, refresh) // 少了这行，拖动阈值画面纹丝不动
```

`useSigmaFilter()` 与 `useSigmaSelection()` 已经替你接好了各自的 `watch`，直接用它们时不必操心。

### 累积对象的契约

::warning
归约函数收到的 `data` 是链内**复用的累积对象**，只在本次调用内有效。要跨调用留存必须复制：

```ts
useSigmaReducer({
  node: (key, data) => {
    snapshot.set(key, { ...data }) // 不复制的话，读到的是后续环写入的值
    return {}
  }
})
```

调用方传入的原始对象不受影响——链在入口处已经复制过一份。详见 [`chainReducers`](/docs/utils/chain-reducers)。
::

归约每帧对每个节点与每条边各跑一次，是热路径。别在里面做 O(n) 查找或分配大对象。

## API

### useSigmaReducer()

`useSigmaReducer(entry: SigmaReducerEntry): UseSigmaReducerReturn`{lang="ts-type"}

作用域销毁时自动注销。

#### Parameters

::field-group
  :::field{name="entry" type="SigmaReducerEntry" required}
  一条归约登记。

    ::::collapsible
      :::::field-group
        ::::::field{name="node" type="SigmaReducer<NodeDisplayData>"}
        节点归约，返回要覆盖的字段补丁。
        ::::::

        ::::::field{name="edge" type="SigmaReducer<EdgeDisplayData>"}
        边归约，返回要覆盖的字段补丁。
        ::::::

        ::::::field{name="order" type="number"}
        默认 `0` —— 链内执行次序，升序执行，后者的返回值覆盖前者的同名字段。
        ::::::
      :::::
    ::::
  :::
::

#### Returns

::field-group
  :::field{name="refresh()" type="() => void"}
  重新合成 reducer 链并让 sigma 重绘。归约结果依赖的状态变化后调用。
  :::
::

`NodeDisplayData` 与 `EdgeDisplayData` 来自 `sigma/types`。本库自己的类型从根出口取：

```ts
import type { SigmaReducer, SigmaReducerEntry, UseSigmaReducerReturn } from '@movk/sigma'
```
