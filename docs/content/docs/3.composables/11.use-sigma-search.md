## 用法

`query` 可双向绑定，`results` 随检索词与图变更自动重算：

:component-example{name="UseSigmaSearchExample"}

```vue [UseSigmaSearchPanel.vue]
<script setup lang="ts">
const { query, results, focus } = useSigmaSearch({ fields: ['label', 'category'] })
</script>

<template>
  <input v-model="query">
  <button v-for="result in results" :key="result.id" type="button" @click="focus(result)">
    {{ result.label }}
  </button>
</template>
```

需要开箱即用的完整检索框（防抖、键盘导航、命中高亮），用 [`SigmaSearchControl`](/docs/components/search-control)；这个 composable 是它的底座，适合自己设计交互时用。

### 匹配规则

子串、大小写不敏感、**不做模糊匹配**，也不支持正则。只有**字符串**类型的属性值参与匹配——数字、布尔、对象一律跳过。

`fields` 按顺序取第一个命中的字段作展示，结果里的 `label` 与 `field` 就来自它。所以字段顺序有意义：把最适合展示的放在前面。

结果次序固定：所有节点命中在前，边命中在后，各自内部落到 graphology 的迭代顺序上。

### 不建索引

匹配在内存里做。`graph.forEachNode` 遍历万级节点是毫秒量级，而维护索引要处理图变更的同步，得不偿失。

::warning
**没有内置防抖。** `results` 是计算属性，`query` 每变一次就全量重扫一遍。直接把它绑到输入框上，万级图会卡输入——请自己加防抖：

```ts
const input = shallowRef('')
const { query, results } = useSigmaSearch()

watchDebounced(input, value => query.value = value, { debounce: 200 })
```

`SigmaSearchControl` 内部就是这么做的。
::

`limit` 只截断结果条数，**不截断遍历**——达到上限后回调仍会为剩余的每个节点执行一次（只是提前返回）。它控制的是渲染量，不是扫描成本。

### 聚焦

`focus()` 把相机移到命中项上，动画时长硬编码 `300` 毫秒。边没有单一位置，解析到 `graph.source(edge)`。

命中项已不在图上、或尚未渲染出显示数据时，静默返回——不抛错，也不移动相机。

需要自定义动画参数就别用它，改调 [`useSigmaCamera().gotoNode()`](/docs/composables/use-sigma-camera)：

```ts
const { gotoNode } = useSigmaCamera()
await gotoNode(result.id, { duration: 600, ratio: 0.4 })
```

## API

### useSigmaSearch()

`useSigmaSearch(options?: UseSigmaSearchOptions): UseSigmaSearchReturn`{lang="ts-type"}

#### Options

::field-group
  :::field{name="fields" type="string[]"}
  默认 `['label']` —— 参与匹配的属性名，按顺序取第一个命中的作展示。
  :::

  :::field{name="limit" type="number"}
  默认 `20` —— 结果条数上限。只截断结果，不截断遍历。
  :::

  :::field{name="edges" type="boolean"}
  默认 `false` —— 是否同时检索边。边命中排在全部节点命中之后。
  :::
::

#### Returns

::field-group
  :::field{name="query" type="Ref<string>"}
  检索词，可双向绑定。空串或全空白时结果为空数组。
  :::

  :::field{name="results" type="ComputedRef<SigmaSearchResult[]>"}
  命中结果，随检索词与图变更重算。
  :::

  :::field{name="focus()" type="(result: SigmaSearchResult) => Promise<void>"}
  相机聚焦到某条结果，动画时长为 300 毫秒。目标不存在时静默返回。
  :::
::

### SigmaSearchResult

::field-group
  :::field{name="type" type="'node' | 'edge'"}
  命中的图元类型。
  :::

  :::field{name="id" type="string"}
  节点或边的 key。用 `id` 而非 `key`，后者是 Vue 的保留属性。
  :::

  :::field{name="label" type="string"}
  用于展示的文本，取自命中的字段。
  :::

  :::field{name="field" type="string"}
  命中所在的属性名。
  :::
::

类型从根出口取：

```ts
import type { SigmaSearchResult, UseSigmaSearchOptions, UseSigmaSearchReturn } from '@movk/sigma'
```
