## API

### useSigmaById()

`useSigmaById(id: MaybeRefOrGetter<string>): ComputedRef<SigmaContext | undefined>`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="id" type="MaybeRefOrGetter<string>" required}
  目标实例的 `id`，与 `SigmaGraph` 的 `id` prop 对应。接受 ref 或 getter，可动态切换目标。
  :::
::

#### Returns

计算属性，目标未挂载或已卸载时为 `undefined`。其值即 `useSigma()` 的返回结构，字段说明见 [`useSigma`](/docs/composables/use-sigma)。

### useSigmaIds()

`useSigmaIds(): ComputedRef<string[]>`{lang="ts-type"}

当前已挂载并登记了 `id` 的全部实例，随注册表增删自动更新。没给 `id` 的实例不会出现在这里。用于做实例切换器，或在开发期确认某个 id 是否真的登记上了。

```ts
import type { SigmaContext } from '@movk/sigma'
```
