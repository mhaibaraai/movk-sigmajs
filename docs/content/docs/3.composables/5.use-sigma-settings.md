## 用法

`SigmaGraph` 的 `settings` prop 已经是响应式的，这个 composable 解决的是**子组件里**要改配置的场景——不必把状态一路上传到根组件：

:component-example{name="UseSigmaSettingsExample" client-only="true" class="example-stage"}

```vue [UseSigmaSettingsPanel.vue]
<script setup lang="ts">
const labels = shallowRef(true)
const density = shallowRef(1)

useSigmaSettings(computed(() => ({
  renderLabels: labels.value,
  labelDensity: density.value
})))
</script>
```

配置对象整体交给 `sigma.setSettings()`，不逐字段枚举也不过滤未知键——sigma 新增的配置项无需本库升级即可使用。

### 深度监听

监听是 `deep: true` 的，改嵌套字段也会重新应用：

```ts
const settings = reactive({ nodeReducer: null, zoomToSizeRatioFunction: fn })
useSigmaSettings(settings) // 改 settings 里任何一层都会触发
```

实例为 `null` 时（SSR、挂载完成前）是空操作，实例出现或被替换后自动重新应用，不必自己等就绪。

### 不要在这里传 reducer

::warning
本 composable 直接调 `setSettings()`。传入的对象里含 `nodeReducer` 或 `edgeReducer` 时，会**覆盖掉库合成好的 reducer 链**——选中高亮、过滤、图例显隐会一起失效，直到下一次链重算。

要往链上加归约，用 [`useSigmaReducer()`](/docs/composables/use-sigma-reducer)。作为链首基座的那条，走 `SigmaGraph` 的 `settings` prop。
::

### 与 settings prop 的分工

两者最终都调 `setSettings()`，选哪个看状态住在哪里：

::field-group
  :::field{name="settings prop"}
  配置由页面持有，或需要与模块选项里的全局 `settings` 深度合并。合并后组件级优先。
  :::

  :::field{name="useSigmaSettings()"}
  配置由子组件持有（控制面板、调试工具）。不参与与全局默认的合并，直接覆盖同名键。
  :::
::

## API

### useSigmaSettings()

`useSigmaSettings(source: MaybeRefOrGetter<Partial<Settings>>): void`{lang="ts-type"}

返回 `void`。停止同步靠作用域销毁。

#### Parameters

::field-group
  :::field{name="source" type="MaybeRefOrGetter<Partial<Settings>>" required}
  配置源，接受普通对象、ref、`computed` 或 getter。深度监听，整体透传给 `sigma.setSettings()`。
  :::
::

`Settings` 来自 `sigma/settings`，需要时从原包直接 import：

```ts
import type { Settings } from 'sigma/settings'
```
