## 用法

:component-example{name="UseSigmaExportExample" client-only="true" class="example-stage"}

```vue [UseSigmaExportPanel.vue]
<script setup lang="ts">
const { download, toBlob, isExporting } = useSigmaExport()

// 直接下载
await download('知识图谱.png', { backgroundColor: '#fff' })

// 或者拿到 Blob 自己处理：上传、放进剪贴板、塞进 PDF
const blob = await toBlob({ width: 1920, height: 1080 })
</script>
```

::warning
需要可选 peer `@sigma/export-image`。未安装时抛出的错误里带有安装命令，捕获后直接展示给用户即可。

它与 sigma 本体一样在模块顶层读 WebGL 全局，所以库内是动态加载的——使用方也不要静态 import 它。
::

### 省略即自动

三个选项省略时传给上游的是 `null`，那是上游表示「自动 / 全部」的取值，不是 `undefined`：

::field-group
  :::field{name="width / height"}
  省略则用当前视口尺寸。给更大的值可以导出比屏幕更清晰的图。
  :::

  :::field{name="layers"}
  省略则导出全部图层。
  :::

  :::field{name="backgroundColor"}
  省略时这个键**整个不传**，得到透明背景的 PNG。
  :::
::

放进浅色文档里的图通常要显式给 `backgroundColor: '#fff'`，否则透明背景在深色主题下会看不清。

### 文件名的 .png 可写可不写

上游会按格式自行追加扩展名，库先把调用方带上的 `.png` 剥掉，所以 `'graph'` 与 `'graph.png'` 得到的文件名一致，不会出现 `graph.png.png`。

`filename` 默认 `'graph.png'`。

::note
`isExporting` 在 `whenReady()` 与动态导入**之后**才置位——首次导出时，等待可选依赖加载的那段时间它还是 `false`。把它绑到按钮的 loading 态上通常没问题，但别指望它覆盖首次加载的全过程。
::

## API

### useSigmaExport()

`useSigmaExport(): UseSigmaExportReturn`{lang="ts-type"}

无选项。

#### Returns

::field-group
  :::field{name="isExporting" type="Readonly<Ref<boolean>>"}
  是否正在导出。
  :::

  :::field{name="toBlob()" type="(options?: SigmaExportOptions) => Promise<Blob>"}
  导出为 PNG 的 `Blob`。
  :::

  :::field{name="download()" type="(filename?: string, options?: SigmaExportOptions) => Promise<void>"}
  导出并触发浏览器下载。`filename` 默认 `'graph.png'`，`.png` 后缀可写可不写。
  :::
::

### SigmaExportOptions

::field-group
  :::field{name="width" type="number"}
  导出宽度，省略则用当前视口宽度。
  :::

  :::field{name="height" type="number"}
  导出高度，省略则用当前视口高度。
  :::

  :::field{name="backgroundColor" type="string"}
  背景色，省略则透明。
  :::

  :::field{name="layers" type="string[]"}
  参与绘制的图层，省略则导出全部。
  :::
::

类型从根出口取：

```ts
import type { SigmaExportOptions, UseSigmaExportReturn } from '@movk/sigma'
```
