## 用法

开箱即用——调用一次就接好了悬浮、点击、高亮、淡出四件事：

:component-example{name="UseSigmaSelectionExample" client-only="true" class="example-stage"}

```vue [UseSigmaSelectionPanel.vue]
<script setup lang="ts">
const { hovered, selected, focused, highlighted, select, clear } = useSigmaSelection()
</script>
```

### 选中压过悬浮

`focused` 是 `selected ?? hovered`——选中之后，鼠标扫过其他节点不会打断当前的焦点。这符合「点开一个节点看详情，同时还能到处指指点点」的操作直觉。

`selected` 是可写的，可以从外部驱动：

```ts
const { selected } = useSigmaSelection()

// 检索命中后同步选中
watch(searchResult, (result) => {
  selected.value = result?.id ?? null
})
```

`hovered` 是只读的，它由鼠标事件唯一决定。

### 归约的具体行为

登记在链上 `order` 默认 `100`。无焦点时全部原样通过；有焦点时：

::field-group
  :::field{name="焦点节点"}
  写 `highlighted: true` 与 `zIndex: 1`。
  :::

  :::field{name="焦点的直接邻居"}
  原样通过，保持原色与标签。
  :::

  :::field{name="其余节点"}
  染成 `dimColor`、`label` 置 `null`、`zIndex: 0`。`dim: false` 时这一档也原样通过。
  :::

  :::field{name="边"}
  与焦点相连的（`hasExtremity`）提到 `zIndex: 1`，其余淡出。`dim: false` 时全部原样通过。
  :::
::

`highlighted` 暴露的就是「焦点 + 直接邻居」这个集合，接自己的 UI 时可以直接用。它只算一度邻居；要更深的范围用 [`useSigmaNeighborhood()`](/docs/composables/use-sigma-neighborhood)。

::note
归约函数本身是常量，变的是它闭包里读的 `focused`。库内已经接好了 `watch(focused, refresh)`，不必自己调 `refresh()`。
::

### 与 useSigmaFilter 联动

被 [`useSigmaFilter()`](/docs/composables/use-sigma-filter) 过滤掉的节点/边默认不响应悬浮与点击，「其余节点」的淡出档也会跳过它们——不这样处理的话，淡出归约会把已过滤节点的透明色改写成不透明的 `dimColor`，等于把它们重新点亮。这个联动经共享的 `SigmaContext` 自动生效，不需要手动接线；只有当你关掉了内置的 `click`/`hover` 自己用 [`useSigmaEvents`](/docs/composables/use-sigma-events) 接管交互时，才需要自己调用 `useSigma().isNodeFilteredOut(key)` 做同样的检查。

### hover 与 click 不是响应式开关

这两个选项只在 setup 时读一次，用来决定要不要绑定对应的事件。挂载后改它们没有效果。

需要运行期开关选中行为，就别用这两个选项——保持默认，然后在自己的逻辑里判断，或者直接操作 `selected`：

```ts
// 用 click: false 关掉内建点击，自己接
const { select } = useSigmaSelection({ click: false })

useSigmaEvents({
  clickNode: ({ node }) => {
    if (canSelect.value) {
      select(node)
    }
  }
})
```

点击已选中的节点会取消选中，点击画布空白处清空。

## API

### useSigmaSelection()

`useSigmaSelection(options?: UseSigmaSelectionOptions): UseSigmaSelectionReturn`{lang="ts-type"}

#### Options

::field-group
  :::field{name="hover" type="boolean"}
  默认 `true` —— 悬浮节点时进入高亮。仅在 setup 时读取一次。
  :::

  :::field{name="click" type="boolean"}
  默认 `true` —— 点击节点选中，再次点击同一节点取消；点击空白处清空。仅在 setup 时读取一次。
  :::

  :::field{name="dim" type="boolean"}
  默认 `true` —— 高亮时把无关的节点与边淡出。
  :::

  :::field{name="dimColor" type="string"}
  默认 `'#d1d5db'` —— 淡出后的颜色。
  :::

  :::field{name="order" type="number"}
  默认 `100` —— reducer 链内次序。过滤是 `50`，图例是 `200`。
  :::
::

#### Returns

::field-group
  :::field{name="hovered" type="Readonly<Ref<string | null>>"}
  当前悬浮的节点。
  :::

  :::field{name="selected" type="Ref<string | null>"}
  当前选中的节点，可写。
  :::

  :::field{name="focused" type="ComputedRef<string | null>"}
  当前焦点，等于 `selected ?? hovered`。
  :::

  :::field{name="highlighted" type="ComputedRef<Set<string>>"}
  焦点节点及其直接邻居。无焦点或焦点已不在图上时为空集。
  :::

  :::field{name="select()" type="(key: string | null) => void"}
  设置选中，传 `null` 清空。
  :::

  :::field{name="clear()" type="() => void"}
  清空悬浮与选中。
  :::
::

类型从根出口取：

```ts
import type { UseSigmaSelectionOptions, UseSigmaSelectionReturn } from '@movk/sigma'
```
