## 用法

v4 把交互状态与图数据分开：`isHovered` / `isHighlighted` / `isHidden` / `isDragged` 这类纯展示态存在 sigma 内部，导出图数据时不会把 UI 状态一并带走。

```ts
const { setNodeState, setNodesState, getGraphState } = useSigmaState()

setNodeState('n1', { isHighlighted: true })
setNodesState(['n2', 'n3'], { isHidden: true })
```

styles 里用 `whenState` 消费这些状态：

```ts
const styles = {
  nodes: {
    color: { whenState: 'isHighlighted', then: '#f43f5e', else: '#94a3b8' },
    visibility: { whenState: 'isHidden', then: 'hidden', else: 'visible' }
  }
}
```

### 自定义标志位

内置状态之外还能加自己的。先在 `SigmaGraph` 上用 `customNodeState` 声明默认值，再用泛型告诉 composable 有哪些键：

```ts
const { setNodesState } = useSigmaState<{ reach: string }>()

setNodesState(['n1', 'n2'], { reach: 'hit' })
```

styles 里用 `matchState` 按取值分支，写法见 [`SigmaGraph`](/docs/components/graph) 的「自定义状态标志位」。键名不能与内置状态冲突。

### 与 useSigmaFilter 的分工

两者最终落在同一个 `isHidden` 状态上：`setNodeState(key, { isHidden: true })` 表达「这个节点被主动藏起来了」，适合「用户点了隐藏」；[`useSigmaFilter`](/docs/composables/use-sigma-filter) 维护一条随时可撤销的谓词，按图数据算出该藏哪些，适合「按条件筛选」。同一个节点被两边同时管时后写的赢，混用要自己划清边界。

::warning
上面示例里 `visibility: { whenState: 'isHidden', then: 'hidden', ... }` 这条 styles 规则和 `useSigmaFilter` 一样要求 sigma 至少为 `4.0.0-beta.3`：更早的版本对 `visibility: 'hidden'` 的处理会让被隐藏的元素错读到纹理里第 0 号元素的数据、渲染成它的副本。症状详见 [`useSigmaFilter`](/docs/composables/use-sigma-filter) 的「sigma 至少要 4.0.0-beta.3」一节。
::

### 图级状态是只读的派生量

`getGraphState()` 返回的 `hasHighlighted` / `hasHovered` / `isIdle` / `isPanning` 等由 sigma 自己维护，读它比自己遍历节点判断便宜得多。styles 规则里想知道「当前有没有焦点」，直接看第三个参数的 `hasHighlighted`。

::note
实例未就绪时写入静默跳过——服务端与挂载完成前都没有实例可写。读取则返回 `undefined`。
::

## API

### useSigmaState()

`useSigmaState<NS, ES, GS>(): UseSigmaStateReturn<NS, ES, GS>`{lang="ts-type"}

三个泛型分别对应 `SigmaGraph` 的 `customNodeState` / `customEdgeState` / `customGraphState`，缺省时只有内置状态。

#### Returns

::field-group
  :::field{name="setNodeState" type="(key: string, state: Partial<FullNodeState<NS>>) => void"}
  设置单个节点的状态。
  :::

  :::field{name="setNodesState" type="(keys: string[], state: Partial<FullNodeState<NS>>) => void"}
  批量设置节点状态，比逐个调用少一次重绘。
  :::

  :::field{name="setEdgeState" type="(key: string, state: Partial<FullEdgeState<ES>>) => void"}
  设置单条边的状态。
  :::

  :::field{name="setEdgesState" type="(keys: string[], state: Partial<FullEdgeState<ES>>) => void"}
  批量设置边状态。
  :::

  :::field{name="setGraphState" type="(state: Partial<FullGraphState<GS>>) => void"}
  设置图级状态。
  :::

  :::field{name="getNodeState" type="(key: string) => FullNodeState<NS> | undefined"}
  读取节点状态，实例未就绪时为 `undefined`。
  :::

  :::field{name="getEdgeState" type="(key: string) => FullEdgeState<ES> | undefined"}
  读取边状态。
  :::

  :::field{name="getGraphState" type="() => FullGraphState<GS> | undefined"}
  读取图级状态。
  :::
::

```ts
import type { UseSigmaStateReturn } from '@movk/sigma'
```
