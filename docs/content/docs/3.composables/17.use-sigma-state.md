## 用法

v4 把交互状态与图数据分开：`isHovered` / `isHighlighted` / `isHidden` / `isDragged` 这类纯展示态存在 sigma 内部，导出图数据时不会把 UI 状态一并带走。

```ts
const { setNodeState, setNodesState, getGraphState } = useSigmaState()

setNodeState('n1', { isHighlighted: true })
setNodesState(['n2', 'n3'], { isHidden: true })
```

styles 里用 `whenState` 消费这些状态：

```ts
const styles = {
  nodes: {
    color: { whenState: 'isHighlighted', then: '#f43f5e', else: '#94a3b8' },
    visibility: { whenState: 'isHidden', then: 'hidden', else: 'visible' }
  }
}
```

### 与 useSigmaFilter 的分工

`setNodeState(key, { isHidden: true })` 表达「这个节点被主动藏起来了」，是一条落在实例上的状态；[`useSigmaFilter`](/docs/composables/use-sigma-filter) 表达的是一条随时可撤销的视图规则。前者适合「用户点了隐藏」，后者适合「按条件筛选」。

::warning
上面示例里 `visibility: { whenState: 'isHidden', then: 'hidden', ... }` 这条 styles 规则会真的把 `NodeDisplayData.visibility` 置为 `'hidden'`——sigma v4-beta 的 WebGL 层对这个值走的是把整个顶点缓冲清零的分支，清零后节点会错读到纹理里第 0 号节点的数据，渲染成它的复制品（详见 [`useSigmaFilter`](/docs/composables/use-sigma-filter) 的「只动视图层」一节）。`useSigmaFilter` 已经改用不触发这个问题的字段组合，但这条路径是你自己写的 `styles` 声明，库管不到。大规模隐藏节点的场景建议优先用 `useSigmaFilter`；确实要用 `isHidden` 状态表达隐藏，就把上面的 `visibility` 规则换成 `opacity: { whenState: 'isHidden', then: 0, else: 1 }` 这类不经过 `visibility` 字段的等价写法。
::

### 图级状态是只读的派生量

`getGraphState()` 返回的 `hasHighlighted` / `hasHovered` / `isIdle` / `isPanning` 等由 sigma 自己维护，读它比自己遍历节点判断便宜得多。归约里想知道「当前有没有焦点」，直接看 `graphState.hasHighlighted`。

::note
实例未就绪时写入静默跳过——服务端与挂载完成前都没有实例可写。读取则返回 `undefined`。
::

## API

### useSigmaState()

`useSigmaState(): UseSigmaStateReturn`{lang="ts-type"}

#### Returns

::field-group
  :::field{name="setNodeState" type="(key: string, state: Partial<BaseNodeState>) => void"}
  设置单个节点的状态。
  :::

  :::field{name="setNodesState" type="(keys: string[], state: Partial<BaseNodeState>) => void"}
  批量设置节点状态，比逐个调用少一次重绘。
  :::

  :::field{name="setEdgeState" type="(key: string, state: Partial<BaseEdgeState>) => void"}
  设置单条边的状态。
  :::

  :::field{name="setEdgesState" type="(keys: string[], state: Partial<BaseEdgeState>) => void"}
  批量设置边状态。
  :::

  :::field{name="setGraphState" type="(state: Partial<BaseGraphState>) => void"}
  设置图级状态。
  :::

  :::field{name="getNodeState" type="(key: string) => BaseNodeState | undefined"}
  读取节点状态，实例未就绪时为 `undefined`。
  :::

  :::field{name="getEdgeState" type="(key: string) => BaseEdgeState | undefined"}
  读取边状态。
  :::

  :::field{name="getGraphState" type="() => BaseGraphState | undefined"}
  读取图级状态。
  :::
::

```ts
import type { UseSigmaStateReturn } from '@movk/sigma'
```
