## 用法

sigma 内置的形状只有圆、方、三角与菱形。类别一多，光靠配色早就分不开了：

:component-example{name="NodeShapeExample" client-only="true" class="example-stage"}

```ts
const primitives = {
  nodes: {
    shapes: [sdfPolygon({ name: 'hexagon', sides: 6 })]
  }
}

const styles = {
  nodes: { shape: { attribute: 'shape', defaultValue: 'hexagon' } }
}
```

节点写 `shape: 'hexagon'` 即命中该形状，属性名由 styles 里的绑定决定。

::note
两个函数返回的都是**纯数据**（`{ name, glsl, inradiusFactor }`），不引用 sigma 的任何值，可以直接写在模块顶层。只有取用 sigma 内置的 `sdfCircle()` / `layerFill()` 时才需要 [`defineSigmaPrimitives()`](/docs/utils/define-sigma-primitives) 延迟加载。
::

### 它是怎么做到的

v4 的节点渲染由一个程序统管，形状是可插拔的**有向距离函数**：给定相对节点中心的坐标 `uv` 与半径 `size`，返回到轮廓的带符号距离，负值在内、正值在外。描边、抗锯齿、拾取全都建在这个返回值上，因此换个距离函数就能换个轮廓，其余机制原样复用。

正多边形把方向角折进单个扇区后，求到最近一条边的垂直距离；星形每个角关于自身中轴对称，折叠到半个扇区即可只描述一条边。

### size 是外接圆半径

与圆形节点的半径同义。同一个 `size` 下多边形看起来比圆略小，那是顶点之间被切掉的部分，属预期。

`inradiusFactor` 是内切半径与外接半径之比，sigma 用它决定标签让多远。正 n 边形取 `cos(π/n)`——正方形因此是 `√2/2`，与内置 `sdfSquare()` 的取值一致。

### 边数不足时退化为圆

`sides` 小于 3 围不出多边形，此时返回圆的距离函数而不是抛错：一条退化数据不该让整张图渲染不出来。`sdfStar()` 的 `points` 同理。

## API

### sdfPolygon()

`sdfPolygon(options?: SdfPolygonOptions): CustomNodeShape`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="options" type="SdfPolygonOptions"}

    ::::collapsible
      :::::field-group
        ::::::field{name="name" type="string"}
        默认 `'polygon'` —— 形状名，用于 styles 的 `shape` 字段。同一实例内注册多个多边形时必须区分。
        ::::::

        ::::::field{name="sides" type="number"}
        默认 `6` —— 正多边形的边数，小于 3 时退化为圆。
        ::::::

        ::::::field{name="rotation" type="number"}
        默认 `0` —— 旋转量（弧度），逆时针为正，0 时首个顶点朝向 +x 轴。
        ::::::
      :::::
    ::::
  :::
::

#### Returns

`CustomNodeShape`，放进 `primitives.nodes.shapes` 数组。

### sdfStar()

`sdfStar(options?: SdfStarOptions): CustomNodeShape`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="options" type="SdfStarOptions"}

    ::::collapsible
      :::::field-group
        ::::::field{name="name" type="string"}
        默认 `'star'` —— 形状名，用于 styles 的 `shape` 字段。
        ::::::

        ::::::field{name="points" type="number"}
        默认 `5` —— 星形的角数，小于 3 时退化为圆。
        ::::::

        ::::::field{name="innerRatio" type="number"}
        默认 `0.5` —— 内接半径与外接半径之比，越小角越尖。取 1 时退化为正 2n 边形。
        ::::::

        ::::::field{name="rotation" type="number"}
        默认 `0` —— 旋转量（弧度），逆时针为正。
        ::::::
      :::::
    ::::
  :::
::

#### Returns

`CustomNodeShape`，放进 `primitives.nodes.shapes` 数组。

```ts
import type { SdfPolygonOptions, SdfStarOptions } from '@movk/sigma'
```
