## 用法

万级节点一次性渲染既慢又看不清。`sampleGraph()` 按度数取前 N 个节点——留下的都是枢纽——再保留两端都入选的边。结果是 `SerializedGraph`，图级 `attributes` 与 `options` 原样保留，可以直接喂给 `SigmaGraph` 的 `data`：

:component-example{name="SampleGraphExample"}

```ts
const overview = computed(() => sampleGraph(full, 200))
```

展示枢纽只是前半程，后半程由 [`useSigmaNeighborhood().expand()`](/docs/composables/use-sigma-neighborhood) 按需把邻域补回来——它内部走 `applyGraphDiff(..., { prune: false })` 增量合入，已经渲染出来的枢纽不重建、坐标不跳。

### 排序只看度数

节点按度数降序排列，`size` 为负时结果为空。度数相同的节点之间不保证稳定次序——落到 graphology 自身的节点迭代顺序上，不要依赖它。

边的去留完全由端点决定：source 与 target 都在入选集合里这条边才保留，因此抽样后的边数下降通常比节点数更陡。

### 全量时的快路径

`size` 不小于 `graph.order` 时**原样返回** `graph.export()` 的结果，不做复制也不做过滤。这是有意的快路径，但也意味着返回值可能与后续的 `export()` 共享同一对象。

## API

### sampleGraph()

`sampleGraph(graph: Graph, size: number): SerializedGraph`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="graph" type="Graph" required}
  源 graphology 实例，只读不改。
  :::

  :::field{name="size" type="number" required}
  保留的节点数。不小于 `graph.order` 时原样返回全图，为负时结果为空。
  :::
::

#### Returns

`SerializedGraph`，类型来自 `graphology-types`，可直接作为 `SigmaGraph` 的 `data`。
