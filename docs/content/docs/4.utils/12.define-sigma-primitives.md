## 用法

sigma v4 的**每个**子路径在模块顶层就读 `WebGL2RenderingContext`——`sigma`、`sigma/rendering`、`sigma/primitives`、`sigma/types` 无一例外。服务端没有这个全局，静态 import 会让 SSR 直接 ReferenceError。

`defineSigmaPrimitives()` 把原语声明包成一个加载函数，`SigmaGraph` 在客户端建实例前才解析它：

:component-example{name="GraphPrimitivesExample" client-only="true" class="example-stage"}

```ts
const primitives = defineSigmaPrimitives(async () => {
  const { sdfCircle, layerFill, pathCurved, extremityArrow } = await import('sigma/rendering')

  return {
    nodes: {
      shapes: [sdfCircle(), sdfPolygon({ name: 'hexagon', sides: 6 })],
      layers: [layerFill()]
    },
    edges: {
      paths: [pathCurved()],
      extremities: [extremityArrow()]
    }
  }
})
```

```vue
<template>
  <SigmaGraph :data="data" :primitives="primitives" :styles="styles" />
</template>
```

::note
本库的 [`sdfPolygon()` 与 `sdfStar()`](/docs/utils/node-shape) 返回纯数据、不引用 sigma 的任何值，可以直接写在外层。只有内置工厂函数需要延迟。
::

### 写成 Promise 不行

```ts
// 错的：Promise 在服务端就开始求值
const primitives = import('sigma/rendering').then(m => ({ ... }))
```

模块级的 `import()` 表达式在服务端同样会被求值。必须是一个**函数**，组件在客户端才调用它。

### 类型也不要从值路径取

```ts
// 对的：import type 编译期擦除
import type { PrimitivesDeclaration } from 'sigma/primitives'
```

`import type` 不会产生运行期 import，安全。

## API

### defineSigmaPrimitives()

`defineSigmaPrimitives(loader: () => PrimitivesDeclaration | Promise<PrimitivesDeclaration>): SigmaLazyPrimitives`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="loader" type="() => PrimitivesDeclaration | Promise<PrimitivesDeclaration>"}
  返回原语声明的函数，可同步可异步。`SigmaGraph` 在创建实例前调用一次。
  :::
::

#### Returns

`SigmaLazyPrimitives`，直接传给 `SigmaGraph` 的 `primitives`。该 prop 同时接受已解析的 `PrimitivesDeclaration`。

```ts
import type { SigmaLazyPrimitives, SigmaPrimitivesSource } from '@movk/sigma'
```
