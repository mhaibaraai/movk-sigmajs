## 用法

`@sigma/*` 程序包与 sigma 本体一样，在模块顶层就读取 `WebGL2RenderingContext`。在 Nuxt 页面里静态 `import` 会让 SSR 直接 ReferenceError，**写成 `import(...)` 的 Promise 也不行**——那同样会在服务端求值。

`defineSigmaProgram()` 接受一个「用到时才执行」的加载函数，`SigmaGraph` 会在创建 sigma 实例之前把它们解析完：

:component-example{name="GraphProgramsExample" client-only="true" class="example-stage"}

```vue
<script setup lang="ts">
const programs = {
  node: {
    border: defineSigmaProgram(() =>
      import('@sigma/node-border').then(m => m.createNodeBorderProgram())
    )
  },
  edge: {
    curved: defineSigmaProgram(() => import('@sigma/edge-curve').then(m => m.default))
  }
}
</script>

<template>
  <SigmaGraph :data="data" :programs="programs" :settings="{ defaultNodeType: 'border' }" />
</template>
```

`programs.node` / `programs.edge` 的键就是节点与边的 `type` 值，写进数据的 `type` 属性或 `settings.defaultNodeType` / `defaultEdgeType` 即可生效。

### 为什么需要一层显式标记

加载函数与程序类本身都是 `function`，运行期无法可靠区分，所以产物是个带 `__sigmaLazyProgram` 标记的对象，而不是裸函数。

`programs` 同时接受已经就位的程序类——sigma 内置的那些不读 WebGL 全局，可以直接静态 import：

```ts
import { EdgeRectangleProgram } from 'sigma/rendering'

const programs = {
  edge: {
    straight: EdgeRectangleProgram, // 内置程序直接给
    curved: defineSigmaProgram(() => import('@sigma/edge-curve').then(m => m.default))
  }
}
```

::note
组件在建实例前解析完全部惰性程序，因此不存在「某个 `type` 已经渲染、但它的程序还没就位」的时间窗。
::

### 不维护白名单

`programs` 接受任何符合 `NodeProgramType` / `EdgeProgramType` 的实现，不限于 `@sigma/*` 官方包。自己写的程序、社区包、经 `createNodeBorderProgram()` 这类工厂现场生成的，都一样传。

## API

### defineSigmaProgram()

`defineSigmaProgram<T>(loader: () => T | Promise<T>): SigmaLazyProgram<T>`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="loader" type="() => T | Promise<T>" required}
  加载函数，返回渲染程序或其 Promise。只在客户端创建实例前调用一次。
  :::
::

### isLazySigmaProgram()

`isLazySigmaProgram<T>(value: unknown): value is SigmaLazyProgram<T>`{lang="ts-type"}

判断某个值是否为 `defineSigmaProgram()` 的产物。`SigmaGraph` 内部用它区分惰性声明与就位的程序，自行封装 `programs` 时才会用到。

### 类型

::field-group
  :::field{name="SigmaPrograms" type="{ node?: Record<string, SigmaProgramSource<NodeProgramType>>, edge?: Record<string, SigmaProgramSource<EdgeProgramType>> }"}
  `SigmaGraph` 的 `programs` prop 类型。
  :::

  :::field{name="SigmaProgramSource<T>" type="T | SigmaLazyProgram<T>"}
  渲染程序，或一个延迟加载它的声明。
  :::

  :::field{name="SigmaLazyProgram<T>" type="{ __sigmaLazyProgram: () => T | Promise<T> }"}
  `defineSigmaProgram()` 的产物。
  :::
::

`NodeProgramType` 与 `EdgeProgramType` 来自 `sigma/rendering`。本库自己的类型从根出口取：

```ts
import type { SigmaLazyProgram, SigmaProgramSource, SigmaPrograms } from '@movk/sigma'
```
