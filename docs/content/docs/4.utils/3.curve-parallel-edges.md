## 用法

多重图上 `a → b` 可以有多条边，默认全部画在同一条直线上、完全重叠。`curveParallelEdges()` 遍历全图，给同一组平行边分配互不相同的曲率，并把它们的 `type` 切到曲线程序：

:component-example{name="CurveParallelEdgesExample" client-only="true" class="example-stage"}

::warning
需要可选 peer `@sigma/edge-curve`。未安装时抛出的错误里带有安装命令，捕获后直接展示给用户即可。
::

### 两步缺一不可

`@sigma/edge-curve` 自带的 `indexParallelEdgesIndex()` 只写 `parallelIndex` / `parallelMinIndex` / `parallelMaxIndex` 三个属性，而渲染程序读的是 `curvature`——**只调它边是不会弯的**，索引本身不参与渲染。

`curveParallelEdges()` 把两步合在一起：先建索引，再按 sigma 官方示例的指数衰减公式把索引换算成曲率，同时设置边的 `type`。

### 与渲染程序的三处对齐

三个选项都是名字约定，必须与你注册的程序对上，否则边要么不弯要么根本画不出来：

```ts
const programs = {
  edge: {
    curved: defineSigmaProgram(() => import('@sigma/edge-curve').then(m => m.default)),
    straight: defineSigmaProgram(() => import('sigma/rendering').then(m => m.EdgeRectangleProgram))
  }
}

await curveParallelEdges(graph, {
  curvedType: 'curved', // 与 programs.edge 的键同名
  straightType: 'straight',
  curvatureAttribute: 'curvature' // 与 createEdgeCurveProgram 的 curvatureAttribute 一致
})
```

单条边不会被标记索引，一律走 `straightType`，也不写曲率属性。平行边关于中轴对称时，居中那条保持 `straightType`，其余向两侧分开。

::note
建多重图时 `multi: true` 必不可少，否则三条 `a → b` 在 graphology 层面就被压成了一条，轮不到曲率登场。
::

### 曲率有渐近上界

换算公式带指数衰减，`3.5 × DEFAULT_EDGE_CURVATURE` 是其渐近上界——平行边再多，最外侧的弧也不会失控地甩出画布。

上游官方实现在 `maxIndex <= 0` 时抛错，这里改为返回 `0`（即不弯）：库不该因为一条退化数据就中断整张图的处理。

## API

### curveParallelEdges()

`curveParallelEdges(graph: Graph, options?: CurveParallelEdgesOptions): Promise<void>`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="graph" type="Graph" required}
  目标 graphology 实例，就地修改。graphology 实例本就是可变数据结构，此处直接写属性是有意为之。
  :::

  :::field{name="options" type="CurveParallelEdgesOptions"}
  类型名与属性名的对齐选项。

    ::::collapsible
      :::::field-group
        ::::::field{name="curvedType" type="string"}
        默认 `'curved'` —— 平行边使用的边类型名，需与 `programs.edge` 里注册的曲线程序同名。
        ::::::

        ::::::field{name="straightType" type="string"}
        默认 `'straight'` —— 非平行边使用的边类型名。
        ::::::

        ::::::field{name="curvatureAttribute" type="string"}
        默认 `'curvature'` —— 写入曲率的属性名，需与 `createEdgeCurveProgram` 的 `curvatureAttribute` 一致。
        ::::::
      :::::
    ::::
  :::
::

类型从根出口取：

```ts
import type { CurveParallelEdgesOptions } from '@movk/sigma'
```
