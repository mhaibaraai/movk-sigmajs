## 用法

sigma 只按标签网格粗筛哪些节点该出标签，位置固定在节点右侧且从不截断。中文长名下这必然糊成一片：

:component-example{name="LabelRendererExample" client-only="true" class="example-stage"}

```ts
const labels = createLabelRenderer({ maxChars: 12 })

const settings = {
  defaultDrawNodeLabel: labels.drawNodeLabel,
  defaultDrawNodeHover: labels.drawNodeHover,
  defaultDrawEdgeLabel: labels.drawEdgeLabel
}
```

```vue
<SigmaGraph :graph="graph" :settings="settings" @before-render="labels.resetFrame()" />
```

::warning
`resetFrame` **必须**挂到 `beforeRender`。少了它上一帧的占位不会释放，第二帧起所有标签都会认为自己被挡住。
::

### 避让怎么工作

每个标签在落笔前先算出自己的占位矩形，向登记表申请。申请失败就换下一个候选位置：

- **节点标签**四个方位轮询，顺序由 `labelPlacement` 属性决定首选（见 [`labelPlacements()`](/docs/utils/label-placements)），其余先补上下再补左右——标签横向占位远宽于纵向。
- **关系标签**沿边三处轮询，先中点再向两端偏。全都冲突时仍在中点绘制，因为关系名往往是图上唯一的语义来源。

节点标签画布固定压在边标签之上（`renderLabels()` 先于 `renderEdgeLabels()`，顺序改不了），所以节点标签总是先占位、关系标签为它让路。也正因如此，文字底色用的是**描边光晕**而不是底衬——成片的底衬会盖住画在下层的关系名。

### 位置要跨帧记忆

每帧独立决策的话，相机一动方位就换，观感是标签集体乱跳。渲染器因此记住每个标签上一次实际采用的位置，下一帧优先复用；悬停态也读同一份记忆，鼠标移上去时标签不会跳位。

重新跑完布局后坐标全变，旧记忆随之作废：

```ts
assignLayout(graph)
labels.clear() // 清空占位与位置记忆
```

### 密集时优雅退化

四个方位全被占的节点标签默认**直接跳过**，只有档位不高于 `forceTier` 的才会强行绘制。没有档位属性的节点一律跳过——这样从「没配档位」到「配了档位」是单调增强，不会突然冒出一堆压盖的标签。

档位怎么来见 [`degreeToTier()`](/docs/utils/degree-to-tier)，怎么随缩放收放见 [`useSigmaLabelTiers()`](/docs/composables/use-sigma-label-tiers)。

### 多个渲染器共用一份占位

同一页两个 `SigmaGraph` 各建各的渲染器即可，状态关在闭包里、互不干扰。反过来若确实需要两套绘制逻辑互相避让，把同一份 `layout` 传进去：

```ts
const layout = createLabelLayout()
const primary = createLabelRenderer({ layout, maxChars: 12 })
const secondary = createLabelRenderer({ layout, halo: false })
```

## API

### createLabelRenderer()

`createLabelRenderer(options?: CreateLabelRendererOptions): SigmaLabelRenderer`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="options" type="CreateLabelRendererOptions"}
  绘制外观与避让行为。

    ::::collapsible
      :::::field-group
        ::::::field{name="layout" type="SigmaLabelLayout"}
        共用的占位登记，缺省各自新建一份。
        ::::::

        ::::::field{name="maxChars" type="number"}
        默认 `0` —— 节点标签保留的最大字符数（按码点计），超出补省略号；`0` 表示不截断。
        ::::::

        ::::::field{name="gap" type="number"}
        默认 `4` —— 标签与节点边缘的间距。
        ::::::

        ::::::field{name="halo" type="SigmaLabelHaloOptions | false"}
        默认 `{ color: 'rgba(255, 255, 255, 0.95)', width: 3 }` —— 文字描边光晕，传 `false` 关闭。
        ::::::

        ::::::field{name="tiers" type="Record<number, SigmaLabelTierStyle>"}
        档位到字形样式（`size` / `weight` / `color`）的映射。未列出的档位与没有该属性的节点回落到 sigma 的 `labelSize` / `labelWeight` / `labelColor`。
        ::::::

        ::::::field{name="tierAttribute" type="string"}
        默认 `'labelTier'` —— 读取节点档位的属性名。
        ::::::

        ::::::field{name="placementAttribute" type="string"}
        默认 `'labelPlacement'` —— 读取节点首选方位的属性名。
        ::::::

        ::::::field{name="extentAttribute" type="string"}
        默认 `'labelExtent'` —— 读取节点各方位轮廓外延的属性名，非圆形节点用它让位，取值可由 `polygonExtent()` 算出。
        ::::::

        ::::::field{name="forceTier" type="number"}
        默认 `0` —— 四个方位全被占满时仍强行绘制的最高档位（含）。
        ::::::

        ::::::field{name="hover" type="SigmaLabelHoverOptions"}
        悬停底衬的 `backdrop` / `shadowColor` / `shadowBlur` / `padding` / `radius`。
        ::::::

        ::::::field{name="edge" type="SigmaEdgeLabelOptions"}
        关系标签的 `ratios`（默认 `[0.5, 0.35, 0.65]`）与 `minChars`（默认 `4`，截断后不足这么多字符就放弃绘制）。
        ::::::
      :::::
    ::::
  :::
::

#### Returns

::field-group
  :::field{name="drawNodeLabel" type="NodeLabelDrawingFunction"}
  交给 `settings.defaultDrawNodeLabel`。
  :::

  :::field{name="drawNodeHover" type="NodeHoverDrawingFunction"}
  交给 `settings.defaultDrawNodeHover`。悬停展示完整名称，不截断。
  :::

  :::field{name="drawEdgeLabel" type="EdgeLabelDrawingFunction"}
  交给 `settings.defaultDrawEdgeLabel`。
  :::

  :::field{name="resetFrame()" type="() => void"}
  交给 sigma 的 `beforeRender` 事件。
  :::

  :::field{name="clear()" type="() => void"}
  清空占位与位置记忆，重新布局后调用。
  :::

  :::field{name="layout" type="SigmaLabelLayout"}
  内部使用的占位登记。
  :::
::

### createLabelLayout()

`createLabelLayout(options?: SigmaLabelLayoutOptions): SigmaLabelLayout`{lang="ts-type"}

占位登记与位置记忆本身。只有在自定义绘制函数、或要让多个渲染器互相避让时才需要直接用。

#### Parameters

::field-group
  :::field{name="options" type="SigmaLabelLayoutOptions"}

    ::::collapsible
      :::::field-group
        ::::::field{name="cellSize" type="number"}
        默认 `64` —— 空间索引的格子边长（像素）。过小则单个标签跨越太多格子，过大则每格内退化成线性扫。
        ::::::

        ::::::field{name="memoryTtlFrames" type="number"}
        默认 `60` —— 位置记忆的保留帧数，连续这么多帧未出现的条目会被淘汰。设为 `0` 则不淘汰。
        ::::::
      :::::
    ::::
  :::
::

#### Returns

`claim(owner, rect)` 申请占位，成功返回 `true`；`occupy(owner, rect)` 无视冲突强行登记；`recall(owner)` / `remember(owner, position)` 读写跨帧记忆；`resetFrame()` 开新帧；`clear()` 全部清空。

::note
登记一律**按 owner 覆盖**而不是追加。悬停走的 `scheduleHighlightedNodesRender` 分支只重画 hovers 与边标签、不发 `beforeRender`，追加式登记会让边标签跟自己上一帧的矩形冲突再挪一次。
::

### buildLabelAnchor()

`buildLabelAnchor(placement: SigmaLabelPlacement, geometry: SigmaLabelGeometry): SigmaLabelAnchor`{lang="ts-type"}

按方位算出占位矩形与绘制原点。上下方位横向居中，左右方位纵向居中并端对齐；让位距离为「该方位上的节点外延加间距」，外延默认取 `size`，经 `geometry.extent` 逐方位覆盖。

### polygonExtent()

`polygonExtent(options: PolygonExtentOptions, size: number): Record<SigmaLabelPlacement, number>`{lang="ts-type"}

算出外接圆半径为 `size` 的正多边形在四个方位上的外延，配合 [`createNodeShapeProgram()`](/docs/programs/create-node-shape-program) 使用：

```ts
graph.setNodeAttribute(node, 'labelExtent', polygonExtent({ sides: 6 }, 14))
```

取的是各顶点在该方向上投影的最大值，也就是包围盒在这个方向上的半宽，而不是该方向射线打到轮廓上的距离——标签是一整条矩形、比节点宽得多，只按射线方向让位的话，轮廓在标签两端翘起来的部分仍会戳进文字里。

本库自己的类型从根出口取：

```ts
import type { CreateLabelRendererOptions, SigmaLabelLayout, SigmaLabelRenderer } from '@movk/sigma'
```
