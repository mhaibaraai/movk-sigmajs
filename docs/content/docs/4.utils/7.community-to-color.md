## 用法

社区检测的输出是「节点 key → 社区编号」，直接拿编号没法画，得先落到颜色上：

:component-example{name="CommunityToColorExample" client-only="true" class="example-stage"}

### 入参是划分结果，不是图

函数吃的是社区映射而非 `Graph`，因此它**不依赖 `graphology-communities-louvain`** 这个可选 peer。手写的划分、服务端下发的划分、Louvain 的输出都能直接喂进来：

```ts
const { communities } = useSigmaMetrics()

const colors = communityToColor(await communities())
```

同理，它也不限于「社区」这个语义。任何把节点分到有限个整数桶里的字段——部门编号、聚类标签、年份分档——都能用它上色。

### 编号越界会回绕

编号超出调色板长度时循环取用，负数编号也能正确回绕，因此 `-1` 这类「未分类」哨兵值不会炸，只是会与某个正常编号撞色。要区分出来就自己排除掉，或者传一个把哨兵位留出来的调色板。

调色板为空数组时返回 `{}`。

::note
默认调色板 `DEFAULT_COMMUNITY_PALETTE` 有 8 种颜色，相邻两色在色相上足够分开：`#f43f5e`、`#3b82f6`、`#22c55e`、`#a855f7`、`#f59e0b`、`#14b8a6`、`#ec4899`、`#84cc16`。
::

## API

### communityToColor()

`communityToColor(communities: Record<string, number>, palette?: readonly string[]): Record<string, string>`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="communities" type="Record<string, number>" required}
  节点 key 到社区编号的映射，通常来自 `useSigmaMetrics().communities()`。
  :::

  :::field{name="palette" type="readonly string[]"}
  默认 `DEFAULT_COMMUNITY_PALETTE` —— 调色板。编号按长度取模回绕，传空数组时返回 `{}`。
  :::
::

#### Returns

`Record<string, string>`，节点 key 到颜色的映射表。

### DEFAULT_COMMUNITY_PALETTE

`DEFAULT_COMMUNITY_PALETTE: readonly string[]`{lang="ts-type"}

内置的 8 色分类调色板，可直接引用做图例配色，与 `communityToColor()` 的默认取值保持一致。
