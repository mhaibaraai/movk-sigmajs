## 变量分两层

内置样式只覆盖控件与覆盖层，画布本身的配色属于 sigma 的 `settings`，不在这里。

变量分两层：**primitive** 是配色与尺寸的原子值，**semantic** 按用途引用 primitive。改主题通常只需覆盖 primitive，要单独调某个控件再覆盖对应的 semantic：

```css
/* 换全局皮肤：只动原子值 */
.sigma-root {
  --sigma-color-accent: #f43f5e;
  --sigma-radius: 10px;
}

/* 只调某一处：动语义值 */
.sigma-root {
  --sigma-control-size: 40px;
  --sigma-minimap-size: 180px;
}
```

变量全部声明在 `.sigma-root` 上，所以既可以挂在 `:root` 全局改，也可以挂在单个实例上局部改。

### primitive

::field-group
  :::field{name="--sigma-color-bg" type="#fff"}
  控件与覆盖层的背景。
  :::

  :::field{name="--sigma-color-fg" type="#1f2328"}
  主文字色。
  :::

  :::field{name="--sigma-color-muted" type="#57606a"}
  次要文字色，也是缩略图节点的默认色。
  :::

  :::field{name="--sigma-color-border" type="rgb(0 0 0 / 12%)"}
  边框色。
  :::

  :::field{name="--sigma-color-hover" type="rgb(0 0 0 / 5%)"}
  悬浮态背景。
  :::

  :::field{name="--sigma-color-active" type="rgb(0 0 0 / 9%)"}
  按下态背景。
  :::

  :::field{name="--sigma-color-accent" type="#3b82f6"}
  强调色。焦点轮廓、检索命中片段、缩略图视口框都用它。
  :::

  :::field{name="--sigma-shadow-sm / --sigma-shadow-md" type="shadow"}
  控件与覆盖层各自的投影。
  :::

  :::field{name="--sigma-radius" type="6px"}
  圆角基准。
  :::

  :::field{name="--sigma-space" type="4px"}
  间距基准。
  :::

  :::field{name="--sigma-font-size" type="13px"}
  字号。
  :::

  :::field{name="--sigma-font" type="system-ui, …"}
  字体族。
  :::
::

### semantic

::field-group
  :::field{name="控件"}
  `--sigma-control-size`（`32px`，按钮边长）、`--sigma-control-gap`、`--sigma-control-inset`（`8px`，与画布边缘的距离）、`--sigma-control-radius`、`--sigma-control-bg`、`--sigma-control-fg`、`--sigma-control-border`、`--sigma-control-shadow`、`--sigma-control-z`（`5`）。
  :::

  :::field{name="覆盖层"}
  `--sigma-overlay-z`（`10`，高于控件）、`--sigma-overlay-bg`、`--sigma-overlay-fg`、`--sigma-overlay-border`、`--sigma-overlay-radius`、`--sigma-overlay-padding`（`6px 10px`）、`--sigma-overlay-shadow`。
  :::

  :::field{name="缩略图"}
  `--sigma-minimap-size`（`140px`）、`--sigma-minimap-node`、`--sigma-minimap-viewport`。缩略图在 JS 里读后两个变量绘制，**没有对应的 prop**，只能这么改。
  :::
::

## 三条深色模式通道

三种切换方式都很常见，所以三条都支持：

::field-group
  :::field{name="系统偏好"}
  `@media (prefers-color-scheme: dark)`，并排除应用强制浅色的情况（`html:not(.light)`）——否则用户手动切到浅色时控件仍是深的。
  :::

  :::field{name=".dark 类"}
  `html.dark`，Nuxt UI 与 Tailwind 的类策略。
  :::

  :::field{name="实例级属性"}
  `.sigma-root[data-sigma-scheme="dark"]`，只让某一张图走深色而不影响页面其余部分。
  :::
::

第三条直接写在 `SigmaGraph` 上即可——`$attrs` 会落到 `.sigma-root` 上：

:component-example{name="ControlsSchemeExample"}

```vue
<template>
  <SigmaGraph :data="data" data-sigma-scheme="dark" />
</template>
```

深色模式只重写 primitive 层的 8 个变量，semantic 层通过引用自动跟随。所以自定义主题时也优先动 primitive，深色模式就能免费得到。

## 覆盖不需要 !important

所有选择器都包在 `:where()` 里，特异性被压到 **0**。使用方的任何一条普通规则都能覆盖它：

```css
.sigma-control-button {
  border-radius: 999px; /* 直接生效，不必 !important */
}
```

::note
少数几个类名（`.sigma-root`、`.sigma-canvas`、`.sigma-overlay`、`.sigma-controls`、`.sigma-control-group`、`.sigma-search`、`.sigma-search-results`、`.sigma-legend`、`.sigma-minimap`）的布局规则写在裸类名上，特异性是 0-1-0。这些是定位与尺寸的骨架，覆盖它们需要同等或更高的特异性。
::

## 类名一览

::field-group
  :::field{name="容器"}
  `.sigma-root`（变量作用域、全屏目标）、`.sigma-canvas`。
  :::

  :::field{name="覆盖层"}
  `.sigma-overlay`（基类，`pointer-events: none`）、`.sigma-tooltip`、`.sigma-popover`、`.sigma-context-menu`。后三者共享一套卡片样式；popover 与 context-menu 额外恢复了 `pointer-events: auto`。
  :::

  :::field{name="控件"}
  `.sigma-controls`（带 `data-position` / `data-direction`）、`.sigma-control-group`、`.sigma-control-button`。
  :::

  :::field{name="检索"}
  `.sigma-search`、`.sigma-search-input`、`.sigma-search-results`、`.sigma-search-option`、`.sigma-search-match`、`.sigma-search-empty`。
  :::

  :::field{name="图例与缩略图"}
  `.sigma-legend`、`.sigma-legend-item`、`.sigma-legend-swatch`、`.sigma-legend-count`、`.sigma-minimap`。
  :::
::

## 完全关掉内置样式

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  sigma: { css: false }
})
```

关掉后控件的**结构与行为不受影响**，只是不带样式——按钮、`aria-*` 属性、键盘导航都还在。配合各控件的插槽，可以用自己的设计系统完全重写外观，同时保留全部行为。
