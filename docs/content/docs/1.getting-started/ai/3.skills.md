## 什么是 Skills？

Skills 是为 AI 编码代理提供库/框架专属知识的结构化文件。与 [MCP Server](/docs/getting-started/ai/mcp) 提供实时工具访问不同，Skill 直接加载进代理上下文，使其在整段对话中都能参考。

文档站提供一个 **usage skill** `movk-sigma`，教 AI 代理用 `@movk/sigma` 构建知识图谱：遵循 [Agent Skills](https://docs.claude.com/en/docs/agents-and-tools/agent-skills) 规范，自动发布到 `/.well-known/skills/` 端点。

## 用法

`movk-sigma` skill 涵盖：

- 安装与 peer 依赖（`sigma` / `graphology`）、Nuxt 模块配置
- `SigmaGraph` 声明式核心范式，显式容器高度
- SSR 下的动态 import 约束、`useSigma()` 必须在子树内调用
- `data` / `graph` 双通道、`styles` 合成、渲染原语与自定义形状
- 一组必须遵守的约定（settings 整体透传、图层生命周期等）

Skill 附带按需加载的 `references/`（components / composables / conventions / recipes），让代理只在需要时拉取细节，保持上下文精简。

::note
查看本站已发布的 Skills：[`/.well-known/skills/index.json`](https://sigma.mhaibaraai.cn/.well-known/skills/index.json)。安装后可在代理聊天中输入 `/movk-sigma` 调用。
::

### Skills CLI

[`skills`](https://skills.sh) CLI 是安装 Skill 最简单的方式，会自动检测已安装的 Claude Code、Cursor、Windsurf 等代理并一并安装：

```bash [Terminal]
npx skills add https://sigma.mhaibaraai.cn
```

::tip
访问 [skills.sh](https://skills.sh) 了解 Skills 生态与更多可用技能。
::

### Claude Code

::note
确保已安装 Claude Code，安装说明见 [Anthropic 文档](https://docs.anthropic.com/en/docs/claude-code/quickstart)。
::

用 CLI 添加技能：

```bash [Terminal]
claude skill add https://sigma.mhaibaraai.cn
```

### Cursor

1. 打开 Cursor，进入「Settings」>「Skills」
2. 点击「Add skill」并填入站点地址：

```text
https://sigma.mhaibaraai.cn
```
