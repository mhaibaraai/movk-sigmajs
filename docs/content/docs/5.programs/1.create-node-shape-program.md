## 用法

sigma 生态只有圆（内置的 `NodeCircleProgram`）与方（`@sigma/node-square`）两种轮廓，后者还不带描边。类别一多，光靠配色早就分不开了：

:component-example{name="NodeShapeExample" client-only="true" class="example-stage"}

```ts
const programs = {
  node: {
    hexagon: defineSigmaProgram(() =>
      import('@movk/sigma/programs/node-shape').then(m => m.createNodeShapeProgram({
        sides: 6,
        borders: [
          { size: { value: 2, mode: 'pixels' }, color: { attribute: 'borderColor' } },
          { size: { fill: true }, color: { attribute: 'color' } }
        ]
      }))
    )
  }
}
```

节点写 `type: 'hexagon'` 即命中该程序，不写则走 `defaultNodeType`（`'circle'`）。

::warning
必须经 [`defineSigmaProgram()`](/docs/utils/define-sigma-program) 延迟加载。本模块静态引用 `sigma/rendering` 与 `sigma/utils`，它们在模块顶层就读 WebGL 全局，直接静态 import 会让 SSR 崩在 `WebGL2RenderingContext`。
::

### 它是怎么做到的

`@sigma/node-border` 的片元着色器整段逻辑建在一行上：`float dist = length(v_diffVector);`，后面所有多环判定都是拿 `dist` 与阈值比。把这行换成别的**有向距离函数**，同一套多环描边、抗锯齿、拾取机制就直接适用于任意形状。

顶点着色器一个字都不用改：它发的是包住外接圆的三角形，任何内接多边形都落在里面。距离函数返回的是「等效外接半径」——点落在轮廓上时恰好等于 `v_radius`，量纲与 `length()` 一致，描边阈值因此不必逐形状重推。

### size 是外接圆半径

与圆形节点的半径同义。同一个 `size` 下多边形看起来比圆略小，那是顶点之间被切掉的部分，属预期。

::note
`@sigma/node-square` 取的是**内切**半径，两者混用时需自行折算：正方形想和圆看起来一样宽，`size` 要乘 `Math.SQRT2`。
::

### 形状默认保持正立

相机旋转时形状不跟着歪——距离函数在求值前把方向反向旋转了 `u_cameraAngle`。要让形状跟着相机转，传 `followCamera: true`。

旋转是在片元里做的，顶点几何不动。反过来若像 `@sigma/node-square` 那样改顶点角度，覆盖三角形会跟着转，边缘会被裁掉。

### 拾取与轮廓一致

拾取分支用的是同一个距离函数，点得中的区域和看得见的形状严格对齐——不会出现「点方形的角点空、点三角形外面反而中」。

### 标签要跟着让位

标签默认按外接圆半径让位，多边形在非顶点方向上的轮廓要近得多。用 [`polygonExtent()`](/docs/utils/label-renderer) 算出各方位的实际外延写进属性：

```ts
graph.setNodeAttribute(node, 'labelExtent', polygonExtent({ sides: 6 }, 14))
```

## API

### createNodeShapeProgram()

`createNodeShapeProgram(options?: CreateNodeShapeProgramOptions): NodeProgramType`{lang="ts-type"}

#### Parameters

::field-group
  :::field{name="options" type="CreateNodeShapeProgramOptions"}

    ::::collapsible
      :::::field-group
        ::::::field{name="shape" type="'circle' | 'polygon' | 'star'"}
        默认 `'polygon'` —— 轮廓形状族。
        ::::::

        ::::::field{name="sides" type="number"}
        默认 `6` —— 正多边形的边数，或星形的角数。小于 3 时退化为圆。
        ::::::

        ::::::field{name="innerRatio" type="number"}
        默认 `0.5` —— 星形的内接半径与外接半径之比，仅 `shape: 'star'` 时生效。
        ::::::

        ::::::field{name="rotation" type="number"}
        默认 `0` —— 整体旋转量（弧度，顺时针）。0 时首个顶点朝向屏幕右方。
        ::::::

        ::::::field{name="followCamera" type="boolean"}
        默认 `false` —— 形状是否跟随相机旋转。默认抵消相机角度，让节点在任何视角下都保持正立。
        ::::::

        ::::::field{name="borders" type="SigmaNodeBorder[]"}
        默认 `[{ size: { value: 0.1 }, color: { attribute: 'borderColor' } }, { size: { fill: true }, color: { attribute: 'color' } }]` —— 由外向内的描边层，与 `@sigma/node-border` 同形。

        `size` 取 `{ value, mode }`（`mode` 为 `'relative'` 按半径比例、`'pixels'` 按固定像素）、`{ attribute, defaultValue, mode }` 或 `{ fill: true }`（均分剩余空间）。`color` 取 `{ value }`、`{ attribute, defaultValue }` 或 `{ transparent: true }`。
        ::::::

        ::::::field{name="drawLabel" type="NodeLabelDrawingFunction"}
        覆盖该形状节点的标签绘制，缺省用 sigma 的 `defaultDrawNodeLabel`。
        ::::::

        ::::::field{name="drawHover" type="NodeHoverDrawingFunction"}
        覆盖该形状节点的悬停绘制，缺省用 sigma 的 `defaultDrawNodeHover`。
        ::::::
      :::::
    ::::
  :::
::

#### Returns

`NodeProgramType`，注册进 `programs.node` 的渲染程序类。

### buildNodeShapeShaders()

`buildNodeShapeShaders(options?: CreateNodeShapeProgramOptions): { vertex: string, fragment: string }`{lang="ts-type"}

单独生成着色器源码。程序类要真实的 WebGL 上下文才能实例化，这个函数把「选项如何变成 GLSL」暴露出来，供调试与测试断言；日常使用不需要。

```ts
import type { CreateNodeShapeProgramOptions, SigmaNodeBorder, SigmaNodeShape } from '@movk/sigma'
```

类型可以随时从根出口取，**值必须走子路径**：从根出口转发会把 WebGL 全局拖进 SSR。
